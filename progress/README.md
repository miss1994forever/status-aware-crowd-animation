# 项目进度工作台

本地、无构建依赖、无外部字体／脚本／网络请求。入口是 `progress/index.html`。可以自行用浏览器打开文件；本次自动浏览器验收使用本机 HTTP，因为内置浏览器的自动化策略不允许导航到 `file:`，直接打开文件的路径没有完成自动验收。

## 本机预览

可以在 Finder 中双击本目录的 `启动工作台.command`，再访问终端显示的地址。该入口更新文档快照并启动本机服务，不安装依赖，也不自动开启浏览器。若 macOS 阻止脚本运行，不绕过安全提示，改用下方命令即可。

在项目根目录运行：

```sh
python3 scripts/build_progress_page.py
python3 -m http.server 8769 --bind 127.0.0.1
```

然后访问 http://127.0.0.1:8769/progress/index.html 。仅监听本机；用 Ctrl+C 结束。端口如被占用可换其他端口，但浏览器个人记录按地址隔离，不会自动迁移。

## 使用

- 任务板按正式状态筛选，也可搜索任务、证据或责任方。
- 展开任务可看证据、下一责任方，以及个人勾选／备注。
- “我已查看”只代表阅读，不等于验收通过；“关注这项”用于个人筛选。
- 个人备注不会自动发给主聊天。需协同时，可导出 JSON 并将文件交给主聊天，或直接在聊天说明。
- 导入前确认；覆盖文件中同名任务的个人记录，未包含的任务保留。不修改正式状态。
- 切换浏览器、清理缓存、从文件模式改为 HTTP 或换端口前，请导出。保存失败会在页内提示，仍可导出本次内存中的记录。
- “材料与记录”显示原始 Markdown 文本快照，支持页内滚动、关闭按钮和 Escape；不是可编辑文档。

## 维护

1. 正式任务状态／证据更新 `docs/任务协调.md` 的四列表格，用户意见更新 `docs/用户样片反馈.md`。
2. 运行 `python3 scripts/build_progress_page.py`，更新 `progress/data.js`。登记在脚本中的项目文档及任务数据自动提取，不手改生成文件。
3. 阶段发生变化时，更新 `index.html` 的阶段导语、阶段条与待讨论卡片；这些是人工策划的概览，不由任务百分比推算。
4. 刷新网页。浏览器个人记录使用任务标题的稳定哈希标识，状态更新不会清空记录；重命名任务会生成新标识，重命名前先导出并按需迁移。
5. 不自动提交 Git、不轮询聊天、不提供在线协作后端。
