# 计算机动画期末大作业

这个仓库用于保存选题讨论、文献线索、研究问题、实验设计和后续实现记录。

截至 2026-10-24，已从选题探索进入第一轮技术与数据可行性实践；尚未形成完整动画原型。这里记录的是“当前理解”和“待验证假设”，不是已经确定的题目或参数。

## 当前兴趣

- 人物根据环境和其他人物改变运动；
- 群组中的人物互动，而不只是互相避碰；
- 动作能够表现不同风格、倾向和人物关系；
- 由局部互动产生更有层次、更具多样性的群组动画；
- 最终成果应符合计算机动画课程要求，并兼顾视觉效果、算法内容、算力和开发可行性。

## 当前最值得继续研究的问题

> 能否让具有不同 status 表达的角色，在适应他人与环境时，产生自然、连贯且大致可辨认的十人到几十人群组动画？

这是截至 2026-10-24 的工作问题，不是最终题目。个人表达与互动响应共同重要；用户仍对“角色估计对方地位”感兴趣，但核心验收先看动作表达与互动效果，显式估计保留为待验证机制；具体参数、动作规则和算法仍未确定。

- 自身预设 status 在一段互动中可以保持固定，不能被其他角色直接读取；对他人的估计根据当前互动更新。
- 保留“稳定地位感＋变化的互动主动权”：高 status 人物可以配合、让别人先通过。
- 环境变化包括空间限制和紧迫性变化，但不能假定越紧急地位差异越明显。
- 最终面向十人到几十人的群组；局部双人分析仅用于检查机制。
- 不以跨次相遇记忆、长期关系学习为核心；社会关系远近留作后续拓展。
- 不急于确定动作和参数；EMM、Social Crowd Simulation 与程序化控制是参考路线，未锁定技术栈。

最新共识、课程限制与工程安排见[两周实践计划](docs/两周实践计划.md)。此前的估计机制候选见[讨论记录的 2026-10-23 检查点](docs/选题讨论记录.md#2026-10-23隐藏-status-估计与情境适应)。早期记录中“不预设固定 status”、关系反转及互动历史等说法保留为探索历史，以最新检查点为准。

## 记录原则

1. 区分灵感来源、研究对象和最终应用场景。
2. 区分事实、文献结论、个人偏好和待验证假设。
3. 先讨论研究问题，再决定参数和实现方法。
4. 每次改变方向时记录原因，不覆盖原先讨论。
5. 选题评价同时考虑课程相关性、创新空间、展示效果、算力和开发风险。
