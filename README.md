# 计算机动画期末大作业

这个仓库用于保存选题讨论、文献线索、研究问题、实验设计和后续实现记录。

目前仍处于选题探索阶段。这里记录的是“当前理解”和“待验证假设”，不是已经确定的题目或参数。

## 当前兴趣

- 人物根据环境和其他人物改变运动；
- 群组中的人物互动，而不只是互相避碰；
- 动作能够表现不同风格、倾向和人物关系；
- 由局部互动产生更有层次、更具多样性的群组动画；
- 最终成果应符合计算机动画课程要求，并兼顾视觉效果、算法内容、算力和开发可行性。

## 当前最值得继续研究的问题

> 能否通过环境感知和局部人物互动，自动生成具有关系差异、且能被观众感知的中小型群组动画？

这只是工作问题，不是最终题目。尤其不能预先假定必须使用固定人格、固定 status 等级或深度学习生成模型。

## 记录原则

1. 区分灵感来源、研究对象和最终应用场景。
2. 区分事实、文献结论、个人偏好和待验证假设。
3. 先讨论研究问题，再决定参数和实现方法。
4. 每次改变方向时记录原因，不覆盖原先讨论。
5. 选题评价同时考虑课程相关性、创新空间、展示效果、算力和开发风险。
