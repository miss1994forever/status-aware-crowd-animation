面向地位差异表达的
群组角色动画

让角色保持自己的表达倾向，同时根据邻近人物与空间变化作出回应。

谁先通过，不等于谁更有地位。

本项目关注人物如何让路、如何收拢或展开身体，以及互动中表达是否连贯。高地位角色也可以配合他人，通行结果与人物印象分别观察。

应用设想：游戏中的群组 NPC，以及电影／动画预演中的群组角色。

研究问题与控制范围

在同一角色模型、共享基础动作的条件下，尝试让预设的地位差异进入身体表达和局部空间回应。

角色知道什么？

每个角色知道自己的 status、目的地与当前运动状态。它可以观察邻人的姿态、位置和速度，但不能读取邻人隐藏的 status。

这里的 status 是创作者设定的连续控制量。最终十人场景取 0、0.5、1 三档，人数分别为 4、3、3；并非经心理学标定的社会地位量表。

角色会改变什么？

空间层选择方向、速度与暂时停让；身体层调节手臂、髋部高度、躯干与头部姿态，并根据当前相遇加入有界回应。

自身 status 在这一场景中保持不变。不使用跨次相遇的长期关系记忆，也没有语言、服装或外貌提示。

从可见线索到连续动画

基础运动交给 EMM，自主模块负责空间决策和表达。点击下面的处理阶段，查看实际输入与输出。

同一时刻的可见快照

每帧先收集所有活跃人物上一帧的最终姿态、位置与速度。用肘部展开量 E 和髋部相对高度 H 描述可见身体线索，再按对象进行低通平滑与观测预热。

没有把邻人的隐藏 status 当作观测输入；这些几何量也不是已经验证的地位识别器。

空间回应：有限候选预测

枚举多个方向与四档速度，预测与邻人的最近接近距离。先比较安全等级，再比较舒适距离、目标进度、运动连续性及绕行代价。

t* = clamp(−r·v / max(v·v, ε), 0, T)
d* = ‖r + v t*‖

r、v 为相对位置和速度；T = 1.8 s。前 0.25 s 使用实测速度，之后再使用候选速度，近似考虑动画响应延迟。

距离怎样参与回应？

基础中心安全距离为 0.60 m、舒适距离为 1.10 m。自身 status 与可见线索估计的差异会增大额外舒适距离；额外绕行过多时，预算机制减弱偏好，但保留基础安全检查。

中心距离只是近似空间约束，不能保证全身网格没有相交，也不把高 status 直接写成“总是先走”。

个体表达：连续控制与约束

自身 status 决定表达基底，相遇的可见线索带来小幅临时偏移。双臂编辑保留前后摆动，主要减少向下外展时的横向分量；前倾与低头是可关闭的附加通道。

b(s) = 0.85 − 0.70s
表达目标 = clamp(b(s) + 临时回应, 0, 1)

临时回应有响应／释放平滑及变化率限制。最终采用稳定下肢 IK、受约束双臂与上身通道，未采用失败的联合高度搜索。

怎样避免动作抖动？

每帧以 EMM 新鲜源姿态为起点，避免重复累积编辑。保留原脚目标，维持膝平面连续性；头部相对胸部先平滑并限制旋转增量，再叠加缓慢的表达低头。

这些约束针对工程连续性，不等同于经过感知实验验证的自然度。

已有模块与自主贡献

EMM 提供基础行走、动作匹配、衔接与重定向。自主部分是局部空间候选选择、可见线索驱动回应、个体表达控制及稳定化整合。没有训练新的神经网络，兼容性补丁不计作原创动画方法。

相同走位，观察身体表达

两版的根位置、移动输入和源动作帧逐帧一致。变化集中在上身通道，可以排除不同走位对这组画面对照的干扰。

哪些迭代真正改变了最终方案？

  1. 时序修改：人物印象变化有限

    改变快慢主要被感知为速度变化；部分慢动作产生年长或迟缓的印象，未得到稳定的地位解释。

  2. 组合表达：比单一通道更容易产生差异

    形成性反馈中，单独收臂偏向不自在，姿态组合更容易带来地位降低的印象。但仍存在疲惫、害羞等混淆。

  3. 稳定性优先：放弃联合高度搜索

    联合搜索曾出现 28／31 次膝部突变，后续修正仍未解决。交付版保留稳定下肢，只整合双臂与上身通道。

  4. 头部与镜头：解决快速点头和观察位置问题

    增加头部限速；近景转向实际相遇更丰富的角色，不改变场景运动轨迹。

已验证到哪一步？

  • 固定场景录制中，全员到达出口。
  • 指定上身对照中的走位、输入与源帧一致。
  • 在 M2 Mac 上脱离编辑器运行独立程序，10/10 人物离场后正常结束。

还不能据此声称什么？

  • 不能声称 status 可被普遍、准确地读出。
  • 不能声称复杂场景或更高密度下仍稳定。
  • 不能把几何约束通过等同于自然、可信的互动。

局限与下一步

当前原型完成了表达与空间回应的连接。下一步应验证可感知的效果，再扩大场景覆盖。

表达是否真的对应地位？

肘部与髋部指标只是原型线索；害羞、疲惫、自信也会影响观众判断。尚未进行独立、多参与者、隐藏标签的感知实验，也没有报告识别准确率或显著性。

后续需要分开评价自然度、人物印象与互动响应感，并在不同动作中复核，避免只对某一种打招呼动作成立。

怎样走向更一般的群组互动？

目前只有单一十人交会场景、一个角色模型；没有全身物理碰撞保证，没有手部接触、语言或主动注视。

后续可增加固定出口、复杂边界和不同紧迫性的场景；同时检查空间安全与表达变化，而不假定紧急情况必然放大地位差异。
