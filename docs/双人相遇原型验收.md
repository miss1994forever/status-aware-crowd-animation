# 双人相遇原型与阶段取舍（2026-10-24）

## 用户反馈与本轮取舍

用户明确反馈“修改版在脚落地前后腿部会出现抖动”，并判断“就目前表现，修改前优于修改后”；同时质疑是否值得继续投入，以及动作基础是否已确定。

本轮按随后“continue”推进：**暂停修脚，以修改前版本作为临时工程基线，保留修正版实验，不将 M01 或当前骨架锁定为最终实验素材。** 原动作页默认改为“原版（当前基线）”，接触版本标为“接触实验版（暂停采用）”，页内记录该取舍并增加新原型入口。刷新旧页面后应用新默认值。

没有删除旧方案或原始数据。本轮修改前的完整产物保存在 `outputs/locomotion-before-encounter/`；更早的路径原版仍在 `outputs/locomotion-before-contact-fix/`。没有继续调整接触阈值、IK、锚或腿部姿态。

## 本轮实现

`src/locomotion_encounter.js` 实现自主编写的局部响应：

1. 每人有当前位置、速度和目标；目标产生期望速度。使用相对位置与期望相对速度计算匀速假设下的最近接近时间和距离。
2. 在 2.2 秒预测范围内发现风险时，保持本次短期相遇的靠右绕行意图，直到对方通过或离开邻近范围，避免预测稍变就左右反复。没有跨次相遇记忆或社交关系。
3. 绕行时改变期望方向，并把期望速度大小降至最多约 78%；当前速度每秒变化不超过 0.8 个参考身高/秒，朝向角每秒变化不超过 1.8 弧度。迎面布置另有软横向边界；没有墙体碰撞保证。
4. 使用固定 1/60 秒步长，同时运行有响应与无响应两个条件，保证起点、目标、名义速度、时间一致；没有按固定时刻播放预制避让曲线。
5. 以每一步实际行进距离累计步态路程，沿当前速度连续转向，复用原有 M01 循环。没有启用足部约束，没有改变骨架源数据；身体不是圆点替代。圆圈仅用于解释简化占地半径。

支持迎面和交叉、2 人或 10 人、三档名义速度、世界斜视/侧视/俯视、轨迹开关、暂停/重置、时间拖动和同一时刻对照。相机范围由两个条件共同确定，切换对照不改取景。场景/人数/速度改变会重置；拖动时间会按当前条件重新计算。

10 人以五组局部相遇作较稀疏的初始布置，响应检查所有邻居，没有特意屏蔽跨组邻居。但它仍不构成拥挤人群、群体组织或社会互动验收。**没有 status，也没有显式决定谁先通过的让行协商。** 这只是下一阶段互动控制的基础。

## 自动证据

```sh
node tests/test_locomotion_encounter.js
python3 -m unittest discover -s tests -p 'test_locomotion*.py' -v
```

本次结果：

- 36 组固定条件：2/10 人 × 迎面/交叉 × 0.6/0.8/1.0 名义速度 × 三种初始间距偏移；每组运行 22 秒。
- 无响应均出现半径圆重叠；有响应在这些条件下重叠采样为零，最小中心距范围约 **0.733–1.699 个参考身高**，简化直径为 0.48；各人最后距目标小于 0.1。
- 默认 2 人迎面、速度 0.8、无间距扰动：完整测试最小中心距约 **0.16055 → 1.60650**，重叠采样 **34 → 0**。
- 将对向邻居放远后，首次响应从约 **2.20 秒推迟到 3.45 秒**；移除邻居后不产生绕行。这验证响应依赖邻居状态，而非单纯时间脚本。
- 检查加速度、朝向变化上限、步态累计路程与实际位移一致、绕行时确实减速、相同初始条件重算一致、零名义速度不推进。
- **9,751 项新 JS 断言通过**；相关 **14 项 Python 测试通过**，包括新页面离线打包、明确不加载足部 IK、旧页默认原版等。原有 120 项运动内核与 28,930 项接触/IK 断言也通过。本轮未重复运行全部其他项目测试。

输出：`outputs/locomotion-encounter/controller-checks.json`、`javascript-tests.txt`、`python-tests.txt`、`regression-tests.txt`。条件数量与断言数量不是独立人体动作或人类评分样本数。

碰撞结果只针对中心占地圆，不是人体网格或肢体碰撞。没有据 36 个构造条件宣称一般避障鲁棒性。

## 未解决与后续判断

- M01 是工程试样，源骨架/动作仍未最终选定；没有用这次局部控制演示替代后续选材和表达验证。
- 绕行幅度较大，两个角色采用统一靠右规则；尚无个体表达差异、先后通行协商、空间受限时的表达调整或地位估计。
- 原版脚滑、快速转向缺少倾身、速度变化缺少专用动作仍存在。接近目标时虽控制速度下降，停下后仍冻结步态，没有自然收脚站定。
- 页面只播放 18 秒有限片段，测试运行 22 秒以检查终点进展；两者不混作同一段视觉验收。
- 10 人只是重复局部试样，不代表几十人密集相遇、复杂环境或性能验收；无物理米制校准。

下一次效果判断应优先看人物遇见对方后，运动响应是否清楚、是否有突兀绕路或转向；不要再以零脚滑为本阶段唯一目标，也不把避让原型当作最终社会互动成果。
