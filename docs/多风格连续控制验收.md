## 一页式结论

**可立即进入N/F工程基线的主要集合：M01/M02/M03向前行走。** 三者共享源骨架、固定M01身高标尺、同一播放器/路径/相位控制；分别保留约0.968 / 0.541 / 0.372身高/秒原生速度。它们是正常/固定表达候选，不是已验证的中/高/低status。M02的49帧周期解决了原24–42帧窗口截短问题，最大节点改动约12.34%→3.56%参考身高；M01/M03无需为了“改进”而强行换周期。

**仍不能用的内容：** M04只有1秒采样跨度，不支持可靠循环；全部素材尚缺经过验证的自然收脚停止、idle、方向切换、转弯专用动作、窄处侧身及其过渡。M08初选区间改动7.03%被拒；第二名区间通过4.87%门槛，作为边界工程候选保留，不推荐直接进入主要N/F集合。其余倒走/斜向片段可作扩展工程观察，不代表已完成方向间切换。`walk-left/right`实测相对身体方向约20–54°斜行，不应直接当90°侧步。

**控制改进有可复核结果，也有明显边界：** 在同一周期上做step/smooth消融，一秒平滑非零减速/恢复使0.8身高/秒条件的最大相邻速度变化0.52→0.00812。没有启用IK或美化肩臂；足部代理仍有高值，转弯只是路径切线旋转，无倾身或步幅空间适应。同速条件把M03加速到约2.15×，只能作为诊断，不能代替原生节奏主比较。

**10/30人已实际运行，但仅是稀疏局部相遇。** 五组/十五组的9秒窗口中中心圆重叠为0，最小中心距约1.609参考身高；不是密集群组或全身碰撞验证。M2本机前台页面约60Hz RAF；原始性能读数与离线计算成本分开保存，见后文。

**下一步G/S缺口：** 先建立带身体占地、空间限制和可执行动作过渡的G，再在同一素材与搜索候选上加入S表达目标。现页没有G/S、隐藏status映射、他人估计或感知实验。需要按当前可见身体状态做几何筛选，不能沿用中心圆无碰撞作为全身可行性，也不能让S独享更好的动作库。

需要用户判断的片段最多三个，均先用“原生节奏／侧面或斜侧面”：

1. M02：直线0–3秒，切“改进所选源周期”与“改进周期”；判断肩部后靠和重复后的观感是否仍可接受。不是要求确认其地位等级。
2. M03：原生与同速直线0–3秒；判断2.15×加速是否已改变其手臂与步态印象。优先决定原生版本是否保留。
3. 三候选减速场景3–7.5秒：观察35%非零速度、恢复后是否仍有明显拖慢或足部违和；此段不表示自然停步。

## 自主算法与失败调查

1. 使用现有`Motion.positions(..., translation_mode='channels_replace_offset')`，保留非根position通道，不重复累加OFFSET。移除合成根但保留Hips及其全身层级。所有片段统一以M01固定身高缩放，另记每条实测头脚高度；不通过各自缩放掩盖比例差异。源片只作固定旋转、统一缩放和起点/地面平移。
2. 用左右脚趾相对Hips的有符号三维位置做相关曲线，左右身份不交换，避免半步当全步。探索滞后0.65–2.8秒，且不超过半个实测跨度；这是工程搜索边界，不是人体生理定律。保留相关峰与分数。
3. M01第一次最强峰为65帧，但33帧单周期峰仅差约0.0025。改为选择与最强峰相关性相差≤0.05、且≥0.65的最短内部局部峰。峰附近±15%搜索允许局部节奏变化。M02全片峰47帧，局部最佳49帧；M03全片峰44帧、局部最佳42帧，说明触及旧上界不等于素材错误。
4. 候选评分为位置RMS＋0.08秒×速度RMS＋0.5×邻域姿态RMS。Hips水平线性漂移被移除，残余上下和横摆保留。边界各留8帧，邻域对齐检查±3帧。固定基线保留24–42帧与原评分；M01与既有`build_cycle`起点、周期、最大改动数值对齐测试通过。其他片段通过适配层使用共同尺度和身体方向，没有修改公共循环器。
5. 复用既有三次C1位置/切线闭合、Hermite采样和固定源中位骨长层级重建。除接缝外，逐节点记录闭合前后改动、骨长变化、最后采样边界差；没有仅把解析端点归零当作验收。最大最终改动5%、原始接缝位置RMS2.5%、最终接缝速度差0.015身高/s、相关性0.65及双周期覆盖是工程门槛，不是自然性阈值。
6. M08证明只取最低接缝分数不够：第1名源帧63–116（界面1基）需7.03%改动；第2名115–167、52帧，分数0.02976→0.03026、改动4.87%。通用改进按原分数检查前8名，取第一个同时过门槛的候选；若均失败仍保留第一名拒绝证据。`closure_trials`完整记录尝试。未降低阈值、未手修姿态。M04因无可靠重复峰直接退出。
7. 相位零点通过左脚相对髋部最前位置选取，只改采样偏移；界面同时显示所选源帧段和当前来源帧。源周期与处理版本共享相位，完整原始模式仍保留完整采样时间。源帧保持与处理插值是明确的显示差异。

## 路径、相位与速度过渡

以绝对秒数计算解析路程，`phase = distance/stride`，不从渲染帧累加相位；30/60/120/144Hz历史积分与解析路程一致。减速从3–4秒降至35%，6–7秒恢复；使用五次smoothstep速度包络和其解析积分，使速度及加速度在端点连续。旧控制在3.5/6.5秒阶跃，9秒累计路程与平滑版相同。矩阵在同一周期上分别测试step/smooth，避免把周期修复与调速改进混为一个贡献。

转弯朝向随弧长按半余弦从0平滑增加至0.9弧度，6身高路程后恒定；0.005身高步长中点积分位置，单测检查局部弧长误差。不是直接混合转向素材。倒走/斜向周期额外保留实测身体相对移动方向。侧移转直走、倒走转向前走及不同风格间混合未实现；显式切换是实验重置或对照，不伪装连续过渡。

相遇原样复用`src/locomotion_encounter.js`，固定1/120秒重算并缓存，按实际行进路程推进不同周期。统一名义速度0.8，原生选择在相遇场景明确忽略。9秒结束前最小速度约0.557，没有把到达后的半步冻结包装为站定。10/30人仍是5/15组稀疏相遇。

脚滑代理定义为脚趾高度小于循环最低点＋0.025身高时的世界水平速度。它包含低位摆脚，非真实支撑标注。原生直线改进版中位数约0.0360 / 0.0197 / 0.0215身高/s，P95约3.147 / 2.139 / 1.656。源片本身同类代理P95约3.029 / 2.076 / 1.535（源采样30Hz，非严格同采样率比较）。高分位没有消失；不追求零脚滑，不据中位数低宣称接触解决。M02同速代理中位数改善但P95增加，是保留多指标的理由。
