# 实验报告材料：个体表达模块

状态：可用于正式报告的技术草稿，依据IE05冻结版本；联合系统结果待整合后补充。学生信息、个人心得和观众评价不代填。

## 目的与输入输出

本模块研究在保留基础动作内容的条件下，如何通过身体空间占用、相对高度和动作姿态产生可调的人物表达，并让角色依据相遇对象的可见身体线索产生短时回应。作者设定的status只作为自身表达的控制输入，尚未证明输出能够稳定表达社会地位。

输入包括本角色status、基础动作、身体尺度、实际移动速度、时间步长，以及邻居可见肘部展开、相对髋部高度、相对位置和速度。输出为连续表达目标及受约束的骨骼修改，不输出路径或通行优先级。独立演示使用两个原有片段及手动相遇上下文；Unity真实群组输入尚待接入。

## 算法原理

个人基底用 b(s)=(1-s)b0+s*b1 定义。IE05加强模式取b0=.85、b1=.15，给相遇回应预留两侧余量。该映射是创作假设，不是从社会地位数据学习的函数。

邻居观测采用 E=dot(左肩-左肘,右肩-左肩)/肩宽²，以及 H=(髋部高度-双脚踝平均高度)/双腿平均长度。按对象ID低通后，以参考中心和尺度归一化，再通过连续死区与tanh得到有界几何评分q。q只表示相对参考的展开/高度变化，不称为真实status。

相遇权重由当前距离、接近速度、预测最近接近距离、测量有效性与观测预热共同决定。所有邻人的权重以max(1,总权重)归一化，使总影响不超过预算。当前函数仅响应接近过程，平行/离开或静止近邻可能不响应，这是设计范围限制。

临时回应 desiredOffset=.15*(.5+.5*(1-s))*sum(w*q)。偏移经过时间平滑与速率限制，叠加个人基底并裁剪到[0,1]。它不改变自身status，无相关邻人时释放回个人基底；保存的是当前相遇滤波，不是跨相遇关系记忆。

身体执行进一步按速度与时间平滑表达目标。组合搜索评估25个高度/手臂候选，在满足腿部约束的条件下权衡目标误差、膝部改变、上臂改变和时间连续性；平滑后的结果重新检查可行性。手臂尽量保留前后摆动分量，限制内收角度并避免越过肩内侧。加强模式角度上限18°，实际执行角通常小于上限。降髋请求最大为参考尺度的1.8%，实际值受约束限制。

可选躯干通道将最多12°前倾分配到脊柱链，头颈通道最多10°俯仰。两者也可能表达疲惫或紧张，不能仅凭角度变化认定地位降低。空间线最新腿IK需在Unity接入时保留，独立实验使用的参考实现不覆盖它。

## 模块与个人实现

- ExpressionPolicy：个人映射、速度调节和连续目标。
- InteractiveExpression：可见线索、相遇权重、多邻人聚合、有界偏移及释放。
- BodyCombinationSearch：有限候选与可行性约束。
- ExpressionMath/PostureChannels：受限手臂与身体子树编辑。
- Round5：独立骨点实验宿主、相同输入的模式对照和双向反馈诊断。

以上为项目自主实现。基础动作来自Bandai Namco Research动作数据，文档记录revision 74ead3ba1ae4696404e6086233779f60de8bf9ef、CC BY-NC 4.0；已修改动作需注明。正式提交仍需附来源与许可文件。Unity系统的动作搜索、基础行走、重定向等来自EMM，不能记为本模块原创。

## 已有结果与边界

IE05保存的检查记录为187050项有限性/几何检查，最大骨长误差约7.04e-7虚拟米，最大实际新增上臂角约11.75°，最大股骨相对源方向修正约11.97°。这些是约束检查次数，不是独立样本数量或感知实验参与者数；不能据此宣称无滑脚或无网格穿插。

独立实时接口记录60次请求，平均计算约1.94ms、平均往返约3.25ms。它不是Unity帧率或十人性能。端点检查中两个角色均出现非零有效偏移，改为4米距离后偏移恢复近零；只证明这些输入下响应与释放执行。

现有视频25.5秒，含行走正面、侧面、侧移和双向互动，采用同一函数输出生成。实时演示的手动距离/接近速度不能作为真实群组导航证据。新增姿态自然度、地位可读性与Unity多人闭环仍待验证。
