# status 数据与表达证据审查

## 2026-10-30 主线校正：从情绪迁移回到 status 表达证据

用户明确追问情绪素材是否偏离研究方向。MOCHA 情绪原片仅作为动作迁移/接触/可控性技术对照，暂停追加情绪训练；不要求用户靠选择情绪来定义 status。项目目标仍是动作表达的相对地位及其互动适应，包含高地位主动配合，不能默认 dominance=全部 status。

本轮重新核查三类原始研究：

- Witkower 等 2020，Two signals of social rank：7 项研究区分 prestige 与 dominance，涉及头姿、不同程度身体扩展及微笑；包含群组互动观察。由于有面部线索，不能把结果直接当作纯骨架移动角色的现成函数，也不能把 prestige 简化为从容。https://pubmed.ncbi.nlm.nih.gov/31021104/
- McCarty 等 2025，Perceiving intimidation through kinematic cues in men’s gait：52 名男性步态、137 名评分者；统一身高体型的无特征角色，侧向躯干摆动与肩外展等与感知身体主导相关。是移动身体证据，但研究身体威慑而非一般社会地位；相关分析不意味着任意增加摆动就能自然表达地位。论文报告 OSF 资料，当前访问未成功，未核实逐条原始 C3D/评分的可下载性。https://pmc.ncbi.nlm.nih.gov/articles/PMC12480651/
- Yang 等 2026，The Motion is the Message：明确区分社会信号判断与自然度；Dominant–Shy 五级任务是向另一人打招呼，不是同内容的五级行走训练对。数据仓库实际存在 5 个 Selected_Mocap_dom-shy FBX（另有两组 HMD 重建）；应优先审查光学 MoCap，不能将 HMD 文件当新增独立表演。仍未观看素材，不据标签声称 status 可读。https://www.cs.ucdavis.edu/~neff/papers/Motion_is_the_Message_TVCG_IEEEVR.pdf ；https://github.com/facebookresearch/MotionIsTheMessageDataset

决策：暂不确定 status 参数数目或权重。先将可测运动特征（空间占用、躯干/头部姿态、步态摆动等）与语义评分分开；提取特征只是描述动作，不是证明地位。下一实践优先审查 Dominant–Shy 光学原片的语义与内容覆盖，保留受尊重但不威胁的候选方向；之后再选择候选控制方向，独立记录地位、威慑、自信、自然度，最后进入让行反转与环境改变的互动检验。没有新训练、Unity 改动或 Git 提交。

## 1. 判断对象与证据等级

本项目的 status 表达目标是“观众从纯身体动作中读出的相对稳定的地位感”。它不能由真实人物的身份、能力、人格或社会等级反推，也不与主导感或当次互动主动权同义。高 status 角色让行完全可以成立，先通过不是地位真值。

| 构念 | 本次证据边界 | 后续分别记录的指标 |
|---|---|---|
| 稳定地位感 | 当前 Bandai 无评分；gait 论文不能直接替本项目证明跨情境稳定地位感 | 单人“显得有地位”评分、双人相对地位判断，以及让行次序反转/空间改变后判断是否保持 |
| 主导感（perceived dominance） | gait 研究直接评分，但其评分不等于本项目的稳定地位感 | 单独的“倾向主导当前局面”评分，不与地位项合并 |
| 当次互动主动权 | 当前试样没有配对互动证据 | 谁发起调整、谁引导响应的观众判断及控制器事件记录；谁先通过另记，不作替代指标 |

以下是本次自定的证据等级，不是通用学术标准；每个维度单独分级，不能以总分掩盖缺项。

| 等级 | 所需证据 | 能支持的表述 |
|---|---|---|
| A | 对应动作有直接目标评分、可追溯刺激与方法 | 在该显示条件和样本中被这样感知；仍不代表真实身份 |
| B | 原始研究直接检验目标，但逐条数据、复现链或本项目迁移缺失 | 方法/假设有依据，不能给当前片段继承标签 |
| C | 有动作或风格/任务标签，但没有对应目标感知评分 | 可作为素材候选或技术参考 |
| U | 来源、许可或目标支持没有核实 | 不能据此宣称有效或可复用 |

## 2. 当前 Bandai 试样审查

本地依据：[pilot manifest](../../data/pilot_manifest.json)、[两周实践计划](../两周实践计划.md)及本次 SHA-256 复核。固定上游 revision 为 `74ead3ba1ae4696404e6086233779f60de8bf9ef`。12/12 文件哈希与清单相同，共 3,749,007 字节；清单播放时长合计 100.4665662 秒。此复核只证明文件身份一致，时长来自已有清单，未独立重算运动学。

抽取方式为 normal / proud / not-confident × walk / walk-back / walk-left / walk-right，每组合取 001，既非随机也未经过视觉筛选。所有 `status_label` 均为空。官方把数据组织为 content 与 style，源于专业演员表演；数据集 1 还明确有同风格内表达变化。因此 **proud ≠ 高 status，not-confident ≠ 低 status，normal ≠ 中 status**。本地没有逐段演员映射、独立 status 评分、双人同步配对或场景条件标签。来源：[官方总说明](https://github.com/BandaiNamcoResearchInc/Bandai-Namco-Research-Motiondataset)、[dataset-1 说明](https://github.com/BandaiNamcoResearchInc/Bandai-Namco-Research-Motiondataset/blob/master/dataset/Bandai-Namco-Research-Motiondataset-1/README.md)。

需要先解决的偏差：

- 时长差异很大：walk-back normal 仅约 1.03 秒，另外两种约 13.03 / 12.13 秒；直接整段并排会暴露节奏、重复次数与样片长度线索。
- backward/sidewalk 的行为语义不同，不能跨 content 排名后归因于 status。各组合只有一个片段，也无法区分风格、表演实例和内容效应。
- 不能从根平移为零判断原地动作；非根 position 通道、尺度、相机、重定向错误都可能影响感知。待工程预览验收后再截取有效步态。
- 自信、情绪、身体扩张、走速都可能影响主导感判断，但在本试样中尚未测出其贡献；不能把这些可见差异写成已验证原因。

## 3. gait dominance 原始材料追查

### 研究实际做了什么

审读版本为 2019-01-07 的 arXiv v1；正式期刊记录为 TVCG 27(6), 2967–2979，2021，DOI `10.1109/TVCG.2019.2953063`。方法细节不能未经核对就称为正式版一致。来源：[预印本](https://arxiv.org/html/1901.02037v1)、[PubMed 正式书目信息](https://pubmed.ncbi.nlm.nih.gov/31751243/)。

v1 §III 使用 CMU 36、ICT 24、BML 119，共 179 条 gait，正面骨架渲染、原采样帧率。703 份参与者响应；问题为 submissive、withdrawn、dominant、confident，各五点量表。逐动作均分经 PCA 合成，再归一化至 [-1,1]、分五类；它们是感知评分，不是原库自带身份标签。§VIII 明确将超过两角色的感知评估、轨迹作用列为未来工作。来源：[v1 §III、§VIII](https://arxiv.org/html/1901.02037v1)。本项目不移植其 PCA 权重、分界或分类器准确率作为验收标准。

### “公开”逐项核对

| 材料 | 本次可核实的状态 | 对本项目的影响 |
|---|---|---|
| 论文全文 | arXiv v1 HTML 可读；作者页另有 PDF，HEAD 返回 200 | 方法可审读；作者 PDF 未下载、未比对版本 |
| 原动作来源 | v1 引用 CMU 官网、Narang 等 2017（ICT）、Ma 等 2006（BML） | 找到来源名称不等于找到论文所选 179 条的精确 ID 与裁剪 |
| 原动作定位与许可 | CMU 本次网页抓取超时；BML 历史 PACO 地址工具不可达；ICT 未在已检查页面发现明确数据入口 | 不能确认当前获取路线，更不能统一宣称三库许可相同 |
| 逐动作评分/个体响应 | 论文有汇总方法；已查论文、作者主页、项目页均未发现可下载评分 CSV、原响应或 ID 对照表 | 不能重建论文标签并回填本地 BVH；“未找到”不等于“作者从未公开” |
| 刺激与演示 | 作者页有约 100 MB 标示的 MP4 链接；HEAD 200，实际 Content-Length 128,445,712 | 仅确认可访问的演示文件；未看视频，未确认含完整 179 刺激，更不是逐刺激包 |
| 材料复用许可 | 已查 dominance 项目区未见评分、刺激、原动作统一开放许可 | 作者网页可访问和 arXiv 论文许可均不能替代动作/视频复用许可 |
| 正式期刊附录 | DOI 入口本次工具不可访问，无法核查全部 supplementary | 不作“没有附录”结论 |

作者入口链：[Tanmay 主页](https://www.cs.unc.edu/~tanmay/) → [GAMMA GAIT 项目页 dominance 区](https://gamma.cs.unc.edu/GAIT/#Dominance_Gait)。可读论文、作者页、项目页及精确标题公开检索均已检查；项目页的 EWalk/DeceptiveWalk 数据入口属于别的任务，不可冒充 dominance 标签包。可手动查阅的演示链接为[作者 MP4](https://gamma.cs.unc.edu/GAIT/videos/Dominance_Gait.mp4)。以上仅证明本次检索边界内的状态。

**决定：**将该研究列为直接主导感方法依据 B，不列为当前可用的有标签动作库 A。若后续发现合法公开的 ID、评分及刺激包，应先逐项补齐来源链再复核，而非现在为此阻塞工程。

## 5. 第一轮小规模盲评方案（待执行）

目的为课程开发筛选，不做总体人群结论，也不宣称复现论文。**第一步先由用户观看匿名预览，做素材/审美预筛**：记录希望保留的自然程度、夸张程度、明显违和及不适用动作。该预筛是创作偏好，不算人群感知验证。完成后再由主聊天结合两周期限决定是否做小规模感知试验及其规模；以下是可选设计，不是已批准的工作、课程验收要求或具有统计依据的阈值。

### 5.1 先过显示与动作质量检查

工程预览先确认层级、通道、单位、朝向、相机与时间正确。给每条源片段分配无含义 ID；受试者界面、文件名、题面均不显示 normal/proud/not-confident，不告诉预期高低。准备者会知道来源，因此只能称“受试者盲于标签”，不能称双盲。

统一骨架、身体比例、灰色材质、无脸无服饰线索、相机和背景。同一 content 内比较；按真实秒播放，不拉伸速度以凑相同时长，不按片段各自最大包围盒缩放身体。先人工标出有效步态区间、去掉准备/收尾。可行时取相同 3 秒；不足则将**整个该 content 组**改为等长较短窗口并标记低信息量。walk-back normal 仅约 1 秒，应先检查是否含完整可用步态；不足一个完整周期则该组三条都退出主比较，不只删除低分样本。不要循环它伪造独立证据。

若决定开展，12–16 名自愿、未参与制作的同学只是一个可选规模，未作功效计算，不保证统计分辨能力；可按实际时间缩小并只做描述性反馈。匿名编号、无姓名等信息，预计每人约 10–15 分钟，可退出。先用一个非正式练习例解释题意。每人随机看全部有效片段，可另加约 20% 重复呈现；随机种子及顺序保存。重复项只测自身一致性，不算新增受试者或独立动作。

### 5.2 分开提问，避免把自信等同地位

每段 1–5 分并提供“看不清/无法判断”：

1. 主导感：“仅从动作看，这个人倾向于主导当前局面。”
2. 地位感：“仅从身体表现看，这个人在群体中显得有地位。”（单人上下文弱，允许无法判断）
3. 自信感：“这个人的身体表现显得自信。”
4. 自然性：“动作自然、连贯。”
5. 违和感：“这个动作显得刻意或怪异。”另用一句话记录最明显线索。

不把这五项相加成一个 status 数字；尤其保留“自信高、地位无差异”的可能。主导/地位的概念说明不举姿态和速度例子，以免教会受试者按预设线索作答。

每个有效 content 再做三种来源的三组无标签配对（左右顺序平衡），问“谁更显得有地位”，可选 A/B/差不多/无法判断。保留后两类，不能剔除后重新计算高正确率。

### 5.3 记录、分析和退出规则

记录源文件哈希、原始帧段、实际显示秒数、视角、是否重定向/循环/调速、匿名参与者、呈现次序、评分、配对选项与自由描述。本任务提供 `data/research/blind_ratings_template.csv` 空模板；没有伪造评分。

- 报告每条中位数、分布、无法判断比例，以及同一 content 的配对方向。以参与者为重采样单位做配对差的 bootstrap 区间；不能把帧、重复播放或同一人多题当独立样本。
- 若主聊天需要数值筛选规则，可讨论采用“至少两个有效 content 中，同一候选相对顺序的配对支持率 ≥70%（分母含‘差不多/无法判断’），自然性中位数 ≥3/5，违和感中位数 ≤3/5”；这些只是未经批准的开发启发式，没有功效或课程评分依据，可以不用。实际采用前需先确定，不能看分后调阈值；即使达到也只能暂时保留，并展示计数与不确定性，不能称统计确证。
- 主导感和地位感方向不一致时分别保留结果，不用自信项补足。只在某个 content 成立就限定该内容使用；没有差异就报告无差异，不能给素材硬分三个等级。
- 如以这批人选出片段，有余力可另招一批验证（例如 8–12 人也仅是规模建议）；不因此默认增加第二轮招募。若无法另招，报告必须标明同批选择与评价偏乐观。若要声称跨视角可读，应另外验证固定斜侧视角，不能由正面结果推断。

### 5.4 第二轮互动与情境检查

以下仅是后续可选诊断，不默认追加本阶段任务。只有用户预筛完成、决定继续评估且工程控制稳定后才考虑。用同一对角色，在开阔/狭窄条件及角色让行次序反转下配对比较；把“谁显得地位更高”“谁主导当前局面”“谁发起调整”“谁先通过”分开问。匹配目标、起点、身材、相机、路径距离，记录真实速度和接近距离；不要在主实验中把所有速度调成相同而消除原表达，必要时另设速度匹配诊断。

对照为无表达、仅个人表达、个人表达＋响应三个版本；另用打乱配对时序的版本检查同步响应贡献，但须明确它是实验对照，不能当自然动画成果。优先 2 人诊断后用同机制的 10/30 人场景检验，报告碰撞、停滞、脚滑、自然性与地位判断。窄处差异减弱是允许结果；不得为了维持排名破坏避碰或强迫高 status 总先行。

## 6. 保留、替换与交付边界

1. **现在保留**全部源文件和原清单；只在研究记录中标记是否适合评分，不改原始标签。先用现有 12 段验证显示，交用户做素材/审美预筛，再决定是否及如何开展小规模感知试验。
2. **发现纯技术缺口再补素材**：walk-back 太短、缺启停或连续转向时，先检索同源其他片段，再少量比较 100STYLE。替换必须记录内容匹配、许可、哈希、选择原因；不按风格名挑“正确答案”。
3. **表达筛选失败时**，停止把这三种源风格用于 status，仍可保留中性 locomotion；可尝试有边界的程序化姿态/步幅/节奏控制并重做盲评。此为后续实现建议，不是本任务已授权修改工程的内容。
4. **环境素材不足时**再核查 EMM 单个 BVH 与骨架兼容性；独立参考环境特征和碰撞惩罚，按课程要求自主实现。不要因有数据包就切换 Unity 主路线。
5. **暂不把 gait dominance 或 dyadic 研究当可用标签库**；当前缺证据应进入报告局限，不扩大抓库或假定获取成功。
