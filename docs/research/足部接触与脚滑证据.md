## 3. 接触检测：用未修正运动推断，保留不确定性

**低脚趾高度不等于支撑。** 摆动开始/落地前可低且快，悬空停顿可低速，脚掌滚动又可能使趾/踝并非同时静止。只有骨架位置，无法验证压力中心、承重或真实摩擦。

建议离线为现有短周期生成左右独立的“候选足趾接触区间”：

1. 从未加锁、未 IK 的源世界轨迹或“局部循环＋恢复直线标称行进”计算趾点三维速度，同时看水平速度、垂直速度及距地面高度。不要直接对去行进后的局部坐标求低速，也不要从已锁住的输出再次识别接触，否则锁定会给自己制造正确标签。
2. 候选使用低速为主、高度接近地面为辅，并检查短时间持续性。记录速度/高度阈值、滤波宽度与原始曲线；均用参考身高及秒。先据当前一周期的曲线与逐帧预览选值，不套用作者的米制阈值。
3. 若原片已经明显滑动、导致没有低速区间，不无限抬高阈值强凑接触；把区间列为不确定，必要时人工标出“视觉候选接触”，保留自动与人工结果的区别。
4. 进入/退出用滞回或时间持续条件去抖；短窗须按秒换算，不能把 60 Hz 的帧数原样用于 30 Hz。过宽滤波会吞掉短接触或错移起止。插值到高采样率只改善数值分析，不增加来源的时间证据。
5. 接触区间跨相位 0/1 时做环形处理，保留同一个跨接缝区间；相位用于提议时序，不随每帧阈值噪声重建锚。再依据运行时可达性和几何条件决定能否锁定。

没有真实标签时只能报告“推断接触/候选支撑”，不能报告检测准确率、召回率或已正确识别承重。单个趾点也不能代表整个鞋底；如无独立 heel 点，无法可靠验证 heel-strike、全脚掌贴合及 heel-to-toe roll。

## 4. 圆形路径：锚要在世界中固定，但必须短时可达

令根位置为 r(t)、朝向矩阵为 R(t)、局部趾点为 p(t)，则世界点为 q(t)=r(t)+R(t)p(t)。其速度由根平移、局部运动及转向三部分组成：

`q̇ = ṙ + R ṗ + ω × (R p)`。

这是当前刚体放置公式的直接推导。圆形路径的偏航角速度大小为 `speed / 3.2`；即使直线的平移与脚部后摆恰好抵消，额外转向项仍可使趾点移动。应对最终世界点做差分测量，不能用直线的“局部足速＋前进速度”替代。

**合理锚定条件：**平地静止、当前是可信的短接触区间、该接触点确实应固定、腿目标仍可达、修正量在限额内。进入区间时取未修正趾世界位置的水平坐标，按趾关节到接触面的偏置设高度，锚不随根旋转或平移。若每帧重新投影新姿态位置，实际仍在滑；若锚放在根局部空间，也会随圆周走。

圆周中的趾点支撑与脚绕趾转动可以兼容，但不等于整个脚掌方向都锁死。只有一个点约束时先保留原踝趾关系，勿无依据固定足朝向。此源动作是直行步态，较急转弯缺少真实内外脚步幅与倾身：锚定只能局部减滑，不能生成可信转弯步态。

**释放条件：**候选接触结束、腿接近不可达、锚与未修正足偏差过大、切换场景/时间跳跃，或用户突然大改速度。对前几项平滑淡出并记录释放原因；不要每帧重锁“刷新目标”，也不要拖着同一锚走完整个圆。双支撑两锚可能共同不可达，固定根路线时无法保证二者都精确满足：优先减弱低置信/超限约束，保留残差，不强拉髋部或伸长腿。

初始化在候选区间中间时没有历史落地点，只能以当前未修正点建立临时锚并标明 warm start。首次一周期与稳定运行应分开检查。若工程要支持拖动时间，需确定重建状态策略，不能把随机 seek 当有历史的连续播放。

## 5. 两段腿 IK 的最小安全条件

以下是本项目适配建议，不是已实现功能清单。

- **链与目标要对应。** 两段链是 hip→knee→ankle/脚根，不能直接把 toe 当两段链末端而忽略固定脚段。若用趾目标，先按未修正姿态的 ankle-to-toe 向量得到踝目标；解腿后保留/适度调整脚段方向，使趾目标相容。这里的 ankle/脚根是骨架链端，不等于真实 heel 接触点。无法识别对应关节时应停止该腿 IK。
- **先混合目标再解保骨长几何。** 可将原趾目标与锚按平滑权重混合，再解腿。不要把两个 knee Cartesian 位置直接线性混合后就称骨长守恒；重建也须复查足部末端残差及后代骨段长度。所有量在同一坐标系中，世界点与局部旋转不可混用。
- **距离与数值夹紧。** 令腿段长 L1、L2，髋至踝目标距离 d，应满足 `|L1-L2|+ε ≤ d ≤ L1+L2-ε`；acos 入参夹到 [-1,1]，零长向量另行分支。ε 应随骨架尺度，不能把作者示例常数当本项目参数。
- **弯曲方向稳定。** 将未修正膝点相对髋—踝轴的垂直分量作为优先弯曲方向；近共线时沿用上次有效弯曲面，或使用随身体朝向运输的参考方向。选与原姿态/前帧连续的解，不能只凭 acos 的无符号角防反折。相反向向量、零叉积须有分支；别用任意固定世界轴让左右腿或转弯时突然翻面。
- **近伸直要柔和退让。** 在可达边界前平滑饱和修正或降权；超限记录锚残差/解锁。硬截断目标可能使速度不连续。当前以固定骨长为优先，不照搬经典方案的小幅伸长；不为精确锁脚持续降低髋部而造成蹲步。
- **权重连续不等于输出连续。** smoothstep 等权重可减少硬开关，但重锚、弯曲分支、可达性 clamp 都可能使最终膝/脚速度突变。需检查锁入、锁出、跨周期和运行时参数变化附近的最终输出，而非只检查权重曲线。
- **零速是特殊状态。** 当前零速冻结步态，可能停在单脚摆动中；不能因所有点世界速度变零就把两脚都判为地面支撑。可以保持已有可达锚，但这不是自动停步或收脚站立。

## 6. 原版/修正版对照与检查清单

先固定同一动作周期、路线、速度历史、初相位、相机及采样时间。建议保留原版 A、接触约束＋IK 版 B；若易于切换，可加“仅目标抬地”诊断版，区分减穿地与减水平滑动，不要求另造展示系统。使用已有浏览器/标准库实现，不引入优化大库；常数规模两腿求解适合 M2 上先实测，不能据算法简单就承诺实时性能。

| 指标 | 记录方式 | 防止误读 |
|---|---|---|
| 全周期足部世界速度 | 左右分别，水平/垂直、median/P95/max，单位参考身高/秒 | 摆动脚本应移动，整体越低不代表越好；与源节奏及修正幅度合看 |
| 推断接触期滑速 | 使用同一份**修正前生成的固定候选掩码**对 A/B 测世界水平速度 | 不准按 B 的低速重新筛选；样本数、覆盖时长、排除与强制释放必须报告 |
| 锚定核心期及边缘 | 核心、锁入、锁出分别统计；记录到锚的水平残差和每步累计水平路程 | 只展示核心零速会隐藏边界跳动；只展示均值会藏掉峰值 |
| 地面误差 | 已知点相对声明平面的有符号高度；全周期最大穿透、候选期悬空量及分布 | toe 骨点不一定在足底，须声明偏置；没有 heel 不宣称整脚无穿地 |
| 骨长 | 每骨段 `abs(length/L_ref-1)` 的最大值与时序，包含踝趾与后代 | 骨长保持不证明关节角自然；同时检查膝弯曲侧/角度突变 |
| 原姿态扰动 | 髋、膝、踝、趾位移 RMS/max；膝弯曲平面及根改动 | 减滑不应靠大幅改变骨架、下蹲或缩短摆脚 |
| 最终连续性 | 相位接缝、圆绕圈、锁入锁出、解锁、暂停恢复附近的位置/一阶速度差 | 用最终 IK 输出，不能只看原闭合场；数值差分跨端点必须包含世界推进 |
| 状态与性能 | 每步重锚次数、超限/强制解锁、约束时长、每帧计算耗时分布 | 减少覆盖或频繁解锁会“改善”滑速；耗时不等于端到端 FPS |

接触指标“全候选掩码”“实际锁住核心”两者都报，防止实现把难帧排出指标。有限差分用真实 dt；至少两种采样步长复查数值稳定性，避免跨开关的中心差分掩盖尖峰。重复周期、多个角色和大量插值帧不是独立动作证据。

- [ ] 单人直线与圆形，各看连续数周期；首次初始化与稳态分开。
