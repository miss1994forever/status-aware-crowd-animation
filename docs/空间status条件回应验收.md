# status 条件空间回应与主动避开人群

2026-11-05。延续用户已认可的稳定膝部版本。新空间策略属于角色行为设计假设，未证明低社会 status 的人普遍存在相同行为。

## 接口与对照

- SpatialPolicy 2：原几何 committed-side 基线。
- SpatialPolicy 5：自己 status 控制目标推进权重；自己 status 与公开身体扩张估计控制成对舒适间距。
- SpatialPolicy 6：在 5 上增加很低 status 对聚集区的提前回避。单个路人不触发聚集区偏好。
- 三种策略共享 0.6m 中心预测安全阈值、原 EMM 执行器、稳定膝部修复；0.6m 不是实测身体无碰撞保证。策略 5 的十人实跑最小中心距离 0.4920354m，不能宣称安全已经解决。
- 自动对照统一 Expression mode、额外 response pose 关闭、seed 806、60Hz、10 人。默认手动场景不自动切到候选策略。

## status 与公开输入

人物自己保存 OwnStatus。通常按 id 循环 0 / 0.5 / 1，双人诊断可交换两人的 low-high/high-low 配置。空间决策读取自己的 status；邻人输入来自位置、速度和上一帧公开 ObservedExpansion，没有读取邻人的隐藏 status。

公开 cue 的校准版本 prototype-elbow-v1：先以 0.35s 滤波扩张量，再 clamp((mean-0.01)/0.16)。观测连续曝光 0.6s 后权重上限 0.5，这个权重不代表经过测量的识别置信度。3m 外或未有姿态则重置到未知中性。没有视锥、遮挡判断或跨相遇记忆。原 belief 列的 0.05/0.7 归一化保留作旧诊断，不是新策略的输入。

校准基于当前 avatar 的旧表达中位数（约 0.009 / 0.088 / 0.165），步态造成明显分布重叠，不能当作可靠的 status 识别。并行表达候选合入后必须重新测量或关闭此 cue，不得沿用阈值并宣称语义一致。

cooperation=clamp(0.5+0.3*(effectiveEstimate-ownStatus))；desiredGap=1.1+0.8*(cooperation-0.5)；comfortMultiplier=0.75+0.5*cooperation；progressWeight=0.65*(0.75+0.5*ownStatus)。方向与权重均为本项目工程选择。

## 从让行到避开聚集区

用户指出所有人物仍明显尽快赶往目标。因此新增独立策略 6，保留策略 5 作为直接对照。低 status 强度为 3*clamp((0.35-ownStatus)/0.35)^2，中高 status 为零。目标推进项始终保留，不是将低 status 的目的地替换为逃离人群。

对每个候选，在未来 0.7 / 1.4 / 2.1 / 2.8s 取样；自己先按实测速度延迟 0.25s 后执行输入，邻人按当前速度外推至最多 1.4s。6m 邻域内使用尺度 1.6m 的高斯密度，减去最强单个邻人，再扣除 0.35 容忍量，正部平方后取均值。该项只依赖公开几何，与成对最近接距离代价分开。

只有低 status 开启此项时才增加 ±90° / ±110° 候选，允许侧移、轻微后撤；原速度档位 1 / 0.7 / 0.35 / 0 保留。安全候选优先和相遇期间侧向承诺仍生效，因此并非任何时候都选密度最低路线。当前为局部前瞻，没有全局路网规划或长期等待耐心状态；需要监测到达与犹豫。

- 双人冻结表达参数，交换两人的 status 后轨迹改变，均完成一次到达。表达参数一致不代表后续源步态姿态一致。

- 原策略 5 十人 35s 均两次到达；其与策略 2 的膝部新增偏移跳变超过 3cm/frame 均为零。
- Unity 启动前自动检查：聚集区前方的低 status 候选应降低预期密度；单人邻域密度项严格为零；0.5/1 的聚集区回避权重为零。失败则不会启动采集。

## 陌生人持续注视修正

用户指出暂缓注意机制后，人物仍持续看邻人。检查发现旧 Response mode 遗留 SprintDirector.LookTarget/HasTarget 驱动 SprintActor 的头部 yaw（限幅 ±35°、乘 response）。该逻辑已移除，所有模式均不再由本层将头转向风险邻人；头部保留源行走动作。未新增扫视、眼神接触、选择性注意或注视状态机。上一轮 Mode 1 / responsePose=false 视频原本就不执行该旧注视，因此该修正直接影响的是手动 Response 模式。

近邻公开几何采样和 prototype-elbow-v1 身体信号估计仍保留，属于空间控制的感知简化：没有视锥/遮挡，不声称人物实际注视或知道陌生人隐藏 status。LookTarget/HasTarget 接口一并删除，避免之后模式切换重新打开旧行为。规划器、身体观察量公式与膝部求解器未更改。

验证：social-no-gaze-response（8s、Mode 2、responsePose=true）确认旧触发条件下身体回应仍运行；social-no-gaze-space（8s、策略 6）与修改前同 frame/id 的 320 条公共样本比较，x/z、observed、arm_deg、lowering、input_x/z 最大差均为 0。源码与 Unity 镜像一致，当前两轮日志无编译错误/Exception/JobTempAlloc/leak，完成后停止 Play。详见 social-no-gaze-audit.json。

## 空旷侧路优先与绕行连续性候选（策略 7）

用户观察：旁边空旷时，角色仍原地等待，转身接停顿不连贯。代码发现原 progressWeight*|candidate-forward|² 对横向速度额外收费，停下可能比侧移便宜；提前回避人群时未触发碰撞风险，heldSide 没有维持，绕行决策缺少连续性。

新增可切换 Crowd flow（策略 7），保留 Crowd aware（策略 6）原行为作对照：仅在 crowdAversion>0 的人物上，将目标项拆成 progressWeight*(1-dot(candidate,goalDirection)) 加 0.8*(1-speed)² 的停慢代价。转向另加 0.35*(1-dot(candidateDirection,previousDirection)) 连续性项。安全判断仍先于这些软代价，不对已验证输入事后插值。

低 status 的角度候选改为 0/±15/±30/±45/±60/±75/±90，去掉策略 6 的 ±110 度后撤候选，减少在空旷处先背离目标再停下的机会。若朝目标方向的预测聚集密度代价 >0.06，维持选定侧；清空后延迟 0.8s 释放。与原相遇侧承诺一样，安全可覆盖方向保持。这仍是局部路径输入的连续选择，不是全局路网绕行，也没有加入头部注意控制。

启动前检查：空旷两侧、前方静止三人群，角色从静止选择至少 0.7 的安全侧向输入；下一次规划保持同一侧且继续移动。半径 0.7m 的八人包围中仍选择安全停止。该检查通过后才允许采集。权重均为工程选择。

第一轮 social-flow-candidate（v6）的实际停顿代理从低 status 四人合计 5.967s 降至 0.750s，但采样相邻有效命令方向变化 >75° 从 4 次增至 7 次，全帧最小中心距离从 0.6143m 降至 0.5344m。因此它只作为过程候选留档，不作为连贯性已改善的证据。

第二轮 v7 增加以先前输入为中心的 0/±180°*dt 三个方向候选，安全候选中优先选择单步朝向变化不超过 180°/s 的候选；没有满足该连续性的安全候选时仍保留其他安全方向。停止仍允许。候选全部经过同一预测检验，不在求解后平滑运动输入。原相遇同侧承诺继续保留，急迫避碰、从静止起步等仍可能产生较大转向，因此不宣称硬性限制每一次最终转向。

## 单程到达退出与二次地位差距距离（v8）

用户确认先改为单程，同时试验更符合“相近地位容许更近、差距大保持距离”的小模型。不引入熟悉度，不把现实群体身份映射为低 status，也不降低高 status 的基本防撞。

### 单程生命周期

SinglePass=true：阶段 0 前往原目的地；距离 <0.65m 后只计一次 arrival，记录 arrival_time 并转入阶段 1；继续通过同一控制器行走到原目的地方向、半径 Radius+3=8m 的出口；距离出口 <0.65m 后阶段 2，记录 departure_time 并关闭该角色根物体。没有到达瞬移或定时强制移除。退出前角色仍作为动态邻人；退出后从几何规划、聚集密度、身体观测和最近距离统计排除。底层 Obstacle.OnDisable 会注销其障碍项，CrowdCharacterController.OnDisable 解除障碍更新订阅。阶段转换统一在每帧快照后、所有角色规划前处理。原往返可通过 --repeat 复现。

画面新增人物编号及 L/M/H 诊断标签、原目标 Goal 编号，到达后目标显示 OK；显示到达/退出计数和人数分布。它们只供观看，不作为角色观察输入，不能用于盲感知评价。低/中/高仍为 4/3/3；到达和退出分别统计，不能把到达当作已离场。运行持续到设定结束，已经离场的人保留审计行但不再运动或生成膝部采样。

### 距离候选

SpatialPolicy 8（Status gap）在策略 7 的路线、连续转向、低 status 聚集区偏好与自身目标坚持权重上，仅替换成对目标间距公式：

`d*=1.1 + q*(0.4*max(0,own-rawEstimate)^2 + 0.6*max(0,rawEstimate-own)^2)`

q 为曝光观测权重（运行上限 0.5，并非经过验证的识别置信度），rawEstimate 来自既有 prototype-elbow-v1 公共扩张滤波。自身 status 真实值只供自己使用；没有邻人隐藏 status 读取。原 social_estimate 列仍是向中性收缩后的有效估计，新增 social_raw_estimate 列才是二次项所用的原始归一化估计；避免混淆。其他舒适权重和 cooperation 诊断仍按旧映射保持，安全阈值和危险项不按 status 修改。

以 q=0.5 为例：自己 1/估计邻人 1→1.1m；自己 1/邻人 0→1.3m；自己 0/邻人 1→1.4m。关闭观测 q=0 时都是 1.1m。数字是受限工程试验，不是研究拟合常数或人的真实地位识别结果。所表达的是相对距离容忍，没有主动吸引同等级人物靠拢，也没有永久通行优先权。

Unity 运行前检查：相近/上下差距的距离方向、未知输入中性回退、固定自身 status 与几何时改变 cue 能影响实际规划命令、退出邻人对几何与密度均无影响。gap-fixtures.json 保存 3×3 自身/估计组合的输入/间距/规划命令。

隔离对照：gap-repeat-parity（策略 7 往返）对前版公共 frame/id 的 320 样本，位置、输入、observed、arm_deg、lowering 最大差均为 0；gap-oneway-baseline（7）与 gap-oneway-candidate（8）同一源码和单程生命周期，只切换距离公式。新的单程结果不能与前一轮往返全程平均指标混作同条件收益。

### 单程退出资源修正（v9）

v8 初版两轮均完成 10/10 到达与退出，旧/新最小中心距离 0.5161637/0.6281336m，但最终日志出现 JobTempAlloc 超过 4 帧生命周期警告，不能标为干净运行。原因：上游 CrowdCharacterController 在 GetNearbyObstacles 分配 TempJob 数组，下一次调用或 OnDestroy 才 Dispose；仅 SetActive(false) 后不再调用更新，也未立即触发 OnDestroy，因此退出角色持有旧临时数组。原持久 NativeList 修复与此无关。上游文件未改。

v9 在外侧出口停用并 Destroy 角色根物体，触发既有 OnDestroy 释放数组。Director 为每个角色保存纯值 PoseSnapshot；退出后不再访问已销毁的控制器或骨架，位置与审计行冻结、膝部采样停止。摄像机和标签对已离场对象使用冻结位置或跳过对象访问。同步放大画面标签，方便查看人数/目标。算法、距离校准与单程条件不变。v8 运行保留 LIMITATIONS.txt，最终以 gap-oneway-baseline-v9 / gap-oneway-candidate-v9 为交付对照。

## 前侧占位与持续并行回应候选（v10，策略9）

用户截图指出：上方 low 长时间与 high 邻近并行，且稍微走在前面，单纯保持距离没有让行感。离线对原策略8轨迹核对：9号与8号确有持续邻近和前侧段；0号与8号并非全程近邻，不把截图透视直接当作完整距离证据。此前间距代价对前后/侧面没有区别，heldSide 又会无条件保持任何安全的同侧候选，可能维持一条社会代价不理想的路线。

策略9保持策略8的二次间距、安全、单程退出、角色比例、身体信号和自身推进权重，新增一个围绕“估计比自己地位高的移动邻人”的方向场。每对临时偏好 deference=q*max(0,rawEstimate-own)，只读取自身status和公开cue，不读取邻人的隐藏status或目标。

按邻人公开实测速度定义前方，速度<0.25m/s时关闭该方向场（对方停下时仍有普通间距与防撞）。在未来0.6/1.2/1.8s对候选输入取样，自己先延迟0.25s，邻人按当前速度外推。令 l 为候选位置相对邻人的前向距离，h²为横向距离平方：

`field = exp(-l*l/8-h*h/(2*1.1*1.1)) * (0.15+0.85*sigmoid(l/0.35))`

再乘deference和同向系数（停止候选为1，其余为clamp((方向点积+0.2)/1.2)），三次取样平均，所有邻人相加后以系数4进入现有评分。前侧比后侧代价大，近侧持续同向也有代价；不会主动吸引角色到固定跟随位，也不强迫所有低status跟在高status后面。它是项目行为设计假设，未证明为普遍人类规律。

为避免被旧侧承诺锁住，当全局候选与同侧候选都预测安全、连续性等级不降低，而且全局评分至少改善0.3时，允许释放旧侧承诺。释放记录为passage_releases，与紧急safety_overrides分开。没有放宽基本防撞，也没有添加头部注视、跨相遇关系记忆或全局路径优先权。

固定场景自检：相同距离下前侧场大于后侧；固定自身status与同向几何时，新项改变实际规划命令；观测权重0时新项严格0。passage-baseline-parity关闭新项，320条原策略8公共样本的位置、输入、observed、social_gap差异均0。
