# 足部接触改进验收（2026-10-24）

**候选支撑段的前脚部点明显更稳定，但进入/退出过渡的足速增加，尚不能称为整体落脚自然性通过。** 没有修改风格、status、原始 BVH 或上半身，也没有实现收脚停步、互动或避障。

## 如何比较

先暂停，选好相机，再切“原版/接触修正版/叠加对照”；版本切换不重置路程或相位。叠加模式灰色为原版，彩色为修正版；人体与相机共用输入。标记开关可单独关闭：绿环表示候选支撑，黄色表示平滑过渡，粉红表示目标不可达。原版中也显示相同候选锚以作比较，不能把显示锚点理解为原版已经施加约束。

环线中“世界侧视”固定于世界轴，并非一直看人物解剖侧面。单人时可勾选“单人随朝向”；十人时该选项禁用。不要用不同相位或不同投影的截图判断修正效果。

## 诊断：源动作、循环与路径放置分开

读取保持主聊天确认的 `channels_replace_offset`，来源、SHA-256 和旧版基线不变。构建结果的 `poses/tangents/stride/parents/bone_lengths` 与备份逐项一致，原版的运行输出也与之前的路径内核逐点一致。

本批骨架只明确含 `UpperLeg → LowerLeg → Foot → Toes → EndSite`。工程将 Foot 作为腿链末端/踝部代理、Toes 作为前脚部标记，**没有明确 heel 或鞋底几何**，不声称恢复了真实脚跟着地或承重状态。

候选推断只读原 BVH 的世界轨迹，且在 IK 之前一次固定生成，联合条件如下：

- Toes 高度距源全片最低 Toes 高度小于 0.012 个固定参考身高。
- Toes 世界水平速度小于 0.18 身高/秒，同时 Foot 世界水平速度小于 0.25 身高/秒；用原始相邻帧中心差分，首尾用单侧差分。
- 连续至少 3 个源帧（约 0.1 秒），移除孤立短段；抽取到周期后按环形区间处理。

这些是保守的**候选**，不是人工支撑标签或检测准确率。低位高速摆脚被速度条件排除；没有从已锁定的输出重新筛选接触，也不会在速度零时把静止摆脚重新判成支撑。

原片 195 帧内，左右分别有 79/78 个候选帧；其 Toes 世界速度中位数约 0.0109/0.0126 身高/秒。所选 32 帧周期对应的原片候选帧为左 13、右 12 帧，原片候选足速均值约 0.0181/0.0190 身高/秒。循环修改与重新沿路径放置后，候选足速增大，说明不能把已有循环闭合当作脚部接触已正确。

最终周期候选区间：左脚相位 `[0.84375, 1.25)`，跨过相位零；右脚 `[0.34375, 0.71875)`。周期长度和源帧仍为原来的 32 帧间隔、第 83→115 帧。

**未发现基线 Toes 穿过显示地面的证据。** 320 相位采样的原版左/右最低世界 Y 约 0.000832/0.003251；用户反馈不被直接归因为穿地。源单位继续不标厘米或米。

## 修正方法及其边界

1. 对每个候选区间，在其 15%、32.5%、50%、67.5%、85% 处求未修正的世界 Toes 位置，取水平均值作为一次固定锚。高度使用该脚原片候选 Toes 的中位高度（约 0.001669 参考身高），作为**关节标记参考面**，没有无依据把 Toes 强压到鞋底平面。
2. 锚由未展开的累计步态路程、候选区间编号和角色相位偏移唯一确定；跨相位零仍沿用同一个世界锚。环线上锚不会随当前根位置或朝向旋转。
3. 候选区间内满权重约束；在其前后各 0.065 周期相位范围用五次平滑函数进入/退出。默认速度 0.8 时每侧约 0.084 秒，速度越快过渡越短。过渡区不伪称为已验证支撑。
4. 混合 Toes 目标后，保留当前源姿态的踝→Toes 向量方向与长度，允许脚部滚动，由 Toes 目标反推踝目标，再解析求 hip→knee→ankle 两段腿。膝弯曲面优先沿用未修正膝点投影，近共线时使用随路径朝向的参考方向；不直接线性混合两个膝位置。
5. 所有腿、足段保持原来的固定骨长；源 EndSite 长度为零才允许随 Toes 同点更新，构建时明确校验，遇到非零后代会拒绝，不静默压成零长。Hips 和非腿节点完全不改，不用全身升降来掩盖脚滑。
6. 不可达时将目标距离限制在两段腿的可达区间，保留锚残差，不拉长骨骼。本次直线/圆线完整采样中，过渡区分别有 11/12 个足部采样触发限制，最大目标距离残差约 0.00272/0.00346 参考身高。**未实现平滑可达性释放**，硬限制仍可能产生速度折点，粉红标记保留这一失败信息。

这是**已知路径的离线约束**：锚计算使用区间未来样本，不是实时落地时锁存。它使任意相位初始化、暂停/重置和 A/B 比较确定一致，但不能直接用于后续未知互动路径、急转或动态地面。该局限在页面内也有说明。

## 固定协议的完整指标

文件：`outputs/locomotion/contact-diagnostics.json`。每场景完整采样 320 个周期相位、左右两脚，共 640 个足部样本；同时包含逐脚 mean/RMS/median/P95/max、有符号最低高度、不可达残差与骨长检查。

同一份原片推断掩码用于前后版本：候选区间共 250 个样本（左 130、右 120），过渡共 82 个（每脚 41）。没有按修正版的低速挑选“好帧”。世界速度由最终输出位置按真实时间中心差分，dt=0.0005 秒。主聊天另以更密采样、两个差分步长及第八角色复核，证据在 `outputs/contact-review/`。
