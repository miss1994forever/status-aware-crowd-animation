# 连续运动原型验收（2026-10-24）

## 阶段结论

已交付独立本地的 M01 连续路径运动原型：自动检测相近步态相位边界、构造连续循环、按路程推进步态、沿直线与弯曲环线连续转向，支持单人与 10 人同场、暂停/重置、速度与视角切换。自动测试及本机浏览器运行检查通过。

**不是互动、避障或 status 系统，也不是最终作业完成。** 十人采用预设等距同速环线或平行分道；没有感知别人、让行或解决交叉相遇。脚滑和转弯时足部侧滑尚未解决。

## 循环、方向与路径实现

1. **固定方向与尺度。** 由整片左右肩的平均水平向量构造一次固定的前向，检查其与净行进方向一致（夹角余弦约 0.997）；得到源前向约 `(0.0720, 0, 0.9974)`。一次固定旋转将其对齐 +Z。以整片中位头点到低侧脚趾点高度约 132.9599 源单位作为统一显示尺度；页面“身高”是这个参考长度，不是米，也不是已确认的物理身高。
2. **检测相位边界。** 搜索间隔 24–42 帧、避开首尾的 2,774 对边界；评分结合去线性水平位移后的全身姿态 RMS 与边界速度差。最终选取 **0-based 82→114，即界面第 83→115 帧**，32 帧间隔、约 1.066666 秒，没有使用全片 195 帧首尾硬接。
3. **保留真实残余运动。** 只减去所选片段首末髋部之间的一条线性水平位移基线，保留髋部的上下变化、横摆及相对这条直线的前后变化。不是每帧把髋部归零，也不逐帧缩放或重新估计朝向。
4. **闭合与插值。** 原始相近相位并非完全相同，用三次修正同时闭合位置及一阶速度；各采样间再用三次 Hermite 插值。关节向量按源动作各骨段的固定中位长度沿层级重建，避免 Cartesian 修正使骨段伸缩。Hips 作为身体根保留残余运动；这不是完整旋转重定向或 IK。
5. **路程驱动。** 所选片段线性水平路程为约 **1.032508 个参考身高**；相位为 `distance / stride mod 1`。每帧只按 `distance += speed × dt` 推进；相同累计路程对应相同步态，速度为零时相位冻结。它没有以固定频率独立迈步。
6. **连续转向。** 直线是无界 +Z 路径，十人各占一条间隔 0.85 的平行线；相机跟随，不通过传送或往返折线重置角色。曲线是半径 3.2 的圆，按弧长解析求位置及切线，使用连续展开的朝向角；绕圈时没有 atan2 角度突跳。十人在圆上等距同向，步态起始相位另加不同偏移。切换路径/人数是用户主动重置场景，不包装成动画衔接。

这些算法为项目内独立实现，只用现有 BVH 和标准库，没有复制外部动画引擎。

| 低脚高启发式下足部水平速度中位数 / 最大值 | 约 0.0957 / 3.2276 身高/秒，378 个足部采样 |

足速检查在直线标称速度下，以脚趾高度距周期最低值小于 0.025 参考身高作为筛选。它**不是来源标注的支撑期**，会包含低位摆脚，最大值不能直接称为支撑脚滑速。该检查和实际样片都不支持“无脚滑”；本阶段没有足部锁定，也没有逐关节作者渲染器对齐。转弯需要将全身沿切线旋转，会进一步产生足部侧滑和缺少倾身的问题。

最终输出的接缝位置与速度连续由数值差分另行测试；不能只用闭合场的解析端点值代替最终重建后的连续性检查。固定骨长会轻微改变原始姿态，最大改动已记录，原始 BVH 保留供对照。

## 限制与交付边界

- 只有一个 normal walk 循环；没有 M02/M03 姿态修饰、status 映射、情境响应、互动、避障、运动匹配或 EMM。
- 只有直线及恒曲率圆；没有曲率变化、急转弯、转弯专用步态、起步/停步和加减速过渡。速度骤变会立即改变节奏；零速会冻结当前姿态，不会自动收脚站定。
- 单一周期重复性明显；固定骨长线框不是蒙皮人物或骨骼局部旋转输出；相机为正交投影。源单位未标米或厘米。
- 没有足部接触约束；保留脚滑与转弯滑动作为下一阶段实际问题，不以“闭合连续”宣称自然运动已经达标。
- 十人只是同场显示与基础计算能力检查；预设中心间距测试不是一般形体碰撞保证，更不代表交互系统已完成。
