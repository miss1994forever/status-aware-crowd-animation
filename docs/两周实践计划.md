## 算法假设与基线设计 v0（2026-10-24，历史讨论稿）

以下保留早期设计用于追溯。2026-10-25 的成功标准与近期实施顺序以文末“互动回应实验 v1”为准；不再把提高 status 辨识率或更多固定混合比例测试作为唯一目标和前置要求。

本节是研究设计提案，不是已实现或用户已确认的动作规则。不预设抬头、肩膀后靠、抬肘等动作对应何种 status，也不把素材原始标签当 status 真值。

### 研究问题与失败条件

在角色需要避让、侧身或减速时，能否在满足通行与动作连续性的前提下，保留观众能大致辨认的相对地位感？高 status 角色允许让路；表达在强限制下允许减弱，不要求每一帧都维持同样强度。

待检验的假设：加入表达目标的情境适应，相比仅考虑通行的适应，能够保留更多可读差异；相比固定个人风格，则能减少不合情境的动作。两项分别评价，不能用通行改善代替表达证据。如果只有自然性改善，或者观众只是依据谁先通过判断，不能认定 status 表达假设成立。

### 文献参照与边界

- [Gait Dominance，III-G](https://arxiv.org/html/1901.02037v1)：已有按目标 dominance 选择步态并结合导航的生成方法，也考虑移动控制要求。适合作为“个人风格加导航”的方法参照；不是稳定社会地位的直接证明。仅给不同角色分配不同走路素材，不足以声称新贡献。
- [EMM，6.1.3–6.1.6](https://arxiv.org/html/2510.22632v1)：已覆盖多人、姿态与路径联合适应及风格素材。不能把增加多人或环境响应当作它没有的功能。我们的候选区别是针对表达保留的控制与感知评价，不是已确认的文献空白。
- [Social Crowd Simulation 官方仓库](https://github.com/ReiyaItatani/SocialCrowdSimulation)：社会力、群组、注视与 motion matching 的系统参考。这里依据仓库说明，不将当前软件架构等同于论文原版，也不声称已完成其复现。

### 分阶段比较条件

| 条件 | 同样具备基础通行能力 | 个人表达与情境响应 | 用途 |
|---|---|---|---|
| N 中性参考 | 是 | 不主动区分 status | 检查表达是否增加可读差异 |
| F 固定表达 | 是 | 保留各自风格，允许正常转向、速度调整与过渡；没有专门的身体表达适应 | 有竞争力的简化基线，不能故意做得僵硬 |
| G 几何适应 | 是 | 从同样个人表达起点出发，身体变化依据环境、连续性等需求，不显式维护表达目标 | 排除改善只是来自更好的身体避障 |
| S 表达感知适应 | 是 | 与 G 共用机制，额外考虑候选动作是否保留个人表达 | 核心待验证版本 |

以上是内部实验条件，不是四篇论文的复现；也不要求一次开发四套系统。先完成 N/F，素材和过渡可行后建立 G/S 开关。F 对 S 检验综合效果；G 对 S 更直接检验表达目标的作用。当前“有响应／无响应直接穿行”仅保留为工程负对照。

公平条件：共享动作来源、角色外观、初始任务、环境、基础导航配置和过渡质量；记录不同条件实际可访问的素材。G/S 应共享候选动作与搜索方式，仅改变表达相关目标。若 S 独享更好的素材，不能把差别归因于算法。主实验不强行统一全部步速和节奏；同路径／同速仅作为诊断，以免删除表达本身。

### 最小控制职责，不锁定实现

输入是自身预设 status 对应的待校准表达目标、当前身体与运动状态、任务和可观察环境；输出是下一段可执行的连续身体动作及与之协调的移动。可采用小型动作选择与混合，也可采用受限程序化调整，暂不指定 EMM 为必选实现。

先保证动作可执行、避免明显穿透，再在可行候选中协调任务、连续性与表达；“表达得更像”不能成为容许穿墙的理由。几何特征只能是表达代理，最终仍需人判断。

角色估计他人 status 保留为独立后续机制：只能依据对方可见动作，不能读取对方预设真值。先有可读表达，再比较“仅响应运动”与“加上估计”的作用，不把第一版不含估计写成永久删去。

### 素材与评价的下一道门槛

先审核现有小样本，不随机扩充整个数据库。需要检查同一候选表达在普通行走、改变移动方向／速度、受限通行与恢复中的覆盖；目前 12 段素材不等于已具备这些连续过渡。M01 不是最终指定素材，M02/M03 也不能机械套用 M01 的步态周期提取设置。

两种互补情境先作为候选：宽空间交汇、空间受限相遇。双人用于看清机制，十人以上用于验证多人同时响应；不以稀疏重复的五组相遇替代多人检验。紧迫度作为之后的情境变化，不立即增加人格参数。

感知问题至少分开问：谁显得地位更高、谁推动了这次互动、动作是否自然；允许“看不出”。对调起点、角色与通行先后，避免把先通过作为答案提示。不能先按同一批观众的评分挑出高低动作，再用这些评分报告识别成功；筛选与验证需分开，用户样片反馈不等于独立验证。

下一步产物应是“小型素材覆盖与过渡可行性表 + N/F 样片”，先让用户参与筛选表达，再实现 G/S。资料、代码和公平对照共同决定最小算法，不能靠不断微调一个走路循环代替研究推进。

## 互动回应实验 v1（2026-10-25）

### 已确认目标与尚未确认的机制

用户确认：只要 status 同样可辨、人物明显更像在相互回应，就有价值。此目标不要求辨识率提高，不意味着现有样片已经有可靠的 status 表达。下面是主控制定的待实施实验规格，不把其所有细节标为用户已确认。

核心比较：在个人表达可读的前提下，基于他人可见表达的即时响应，能否比“个人表达＋几何避让”带来更明确的相互回应感？自然性、安全性与通行能力是独立约束。最终十人至几十人目标不变；局部相遇用于定位因果，不替代多人交付。

### 三个实验条件：共用同一实现，用开关消融

| 条件 | 几何避让 | 个人表达 | 他人可见表达影响回应 |
|---|---|---|---|
| C0 几何参考 | 有 | 不主动区分地位 | 无 |
| C1 个人表达基线 | 有 | 有，允许正常身体/空间适应 | 无 |
| C2 表达驱动互动 | 与 C1 相同 | 与 C1 相同 | 有，仅使用可见动作与环境 |

主比较为 C2 对 C1，C0 只帮助检查个人差异本身。C 编号不覆盖既有 F/G/P、R0/R1 实验。C1 不能故意做僵硬、不看障碍或不能侧身；C1/C2 共用动作资产、身体控制自由度、导航、安全检查、初始状态和镜头。不得让 C2 独享新动作库再把收益归因于推断。

辅助诊断 C2-yoked：重放其他匹配遭遇的社会响应控制信号，而不是对眼前人物作社会解释；保留对当前真实身体的安全检查。不改骨架帧或伪造碰撞。尽量匹配控制信号的幅度/频次，记录安全裁剪后的实际动作量，不宣称严格相等；时序错配本身可能造成不自然，因此它只诊断“变化多”与“针对当前对象”，不能单独证明正确推断 status。

### 模型接口与防止隐藏信息泄漏

1. 自身私有状态可包含预设 status、自己的任务和运动状态；status 到动作表达的映射待校准，M01–M03 不直接标高低地位。
2. 邻人输入只提供位置、速度、可见身体姿态和同一次遭遇内的短时间观察。不能读邻人的真实 status、风格标签、目标、未来动作计划。环境可见性/遮挡需明确实现或列为理想化假设。
3. 判断层保留不确定性；看不到、线索不足时退回几何响应，不凭空输出确信等级。先比较简洁可解释估计与不估计条件，不预定必须采用完整贝叶斯模型。
4. 响应层输出短时控制目标/响应时序，再由连续骨骼控制执行，不输出预设“谁必须让路”。身体调整与移动需协调，调整后的身体仍参与安全检查。
5. 同一次互动可连续更新，遭遇结束清除临时观察；没有跨次相遇记忆。多人同时更新采用同一时刻快照，避免遍历先后被误读成 status 效果。

先做工程信息隔离检查：固定可见观测，改变不可见邻人标签，不应改变自身决策；反之，固定几何轨迹并改变确实可见的表达线索，允许响应变化。后者需控制身体占地差异，或用仅切换社会输入、保留真实几何安全输入的诊断排除混淆。该诊断不是独立人类证据。

### 场景与实验纪律

- 首个开发场景：开放十人交汇，存在同一角色先后面对多名邻人的真实交互，而非五组独立双人；复用现有场景设施，但新增实验不冒充既有冻结结果。
- 局部诊断：从明确的相遇条件检查响应时机及因果，保留对调起点、角色与优先通行结果的版本。高 status 先让路是必须覆盖的情况，不要求每帧恒定地位感。
- 泛化检查：未参与调参的随机种子与空间约束变化。已有极窄通道导航失败继续单列，不把无法通行直接归因于社会表达模型。十人先跑通，30 人仍需独立验证成本、稳定性与观感。
- 先固定开发/评价划分、记录配置与版本，再生成比较样片。反复查看并调参的评价条件降为开发集，不能再称留出。
- 感知评价盲化条件名和预设等级；角色外观一致、位置/标识对调，避免颜色、镜头中心或先通过的人提示答案。不由模型自产等级评分证明模型成功。

### 分开评价，不制造“等效”结论

1. status 可读性：谁显得地位更高，允许差不多/无法判断；先确认 C1 有可读差异，再比较 C2。两组都不可辨不能称保持成功。
2. 相互回应感：人物是否看起来在根据对方的举动调整，而不是各自动作较丰富。配对比较允许无差别，不向观看者透露预期。
3. 自然性与混淆项：分别记录动作自然性、谁推动互动、谁先通过；不将“很强势”自动等同稳定地位。
4. 工程：实际身体代理穿透、停滞/到达、姿态连续性、逐帧可见输入与响应日志、运行成本；代理检测不等于物理网格安全或人类感知。

初期小样本仅用于排错、表达筛选与效应估计，不宣称统计非劣。正式声称“status 不劣于基线”需要在评价前确定可接受下降幅度、分析方法和人数依据，并报告不确定性；无显著差异不等于同样可辨。用户作为共设计者的反馈与独立观看者验证分开。

### 下一项交付与停止条件

下一项代码工作是隔离的互动接口/诊断原型：保留旧控制器与样片，用 C1/C2 开关、观察日志和隐藏信息不泄漏测试，检查可见表达是否真正影响响应。此后接入连续身体调节，再提供短局部对照及同机制十人回放；接口跑通本身不算表达成功。具体动作线索与参数仍通过小样片/文献和用户参与筛选，不预设奇怪姿势作为等级标记。

若 C1 无可读差异，先修正表达素材或映射，同时保留交互工程；若 C2 只增加动作量、没有回应优势，不堆参数，而检查观察是否有用及响应是否相关；若回应提升却牺牲自然性或造成频繁僵持，报告权衡，不宣布达成最低成功标准。

1. **目标改为解决已定位缺陷，不再只交模块。** 必须建立自身稳定特点与可见对方判断共同影响响应的机制，说明相同他人观测、不同自身设定为何会产生不同合理响应；不将固定躯干倾角当作全部status建模，不把高status设为必然先过。

3. **有意义的替代机制，而非只扫强度。** 针对当前失败比较结构上不同且有文献/动画依据的可行候选，例如明确当前回应对象与有限持续时序，对比当前多人加权单转角。具体头/躯干/手臂分配和时序属于可替换试验，不锁定为status真理；单纯放大旋转、放大镜头或放慢播放不能单独过关。

5. **完成、候选交付与研究成功分开。** 工程候选就绪需要针对已知缺陷的修订证据、可执行连续动作、对照与失败分析、视觉排错及可重现性。人的回应感/status结果仍待评，不因无人值守编造通过；若效果始终弱，报告未解决的具体障碍与已尝试机制，而非把原型清单完成写成效果改进成功。Goal状态严格遵循工具关于完成/阻塞/预算的规则，不要求无证据无限运行。
