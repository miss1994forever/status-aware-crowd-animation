# IE-04：互动表达的五个具体函数

2026-11-05。用户要求继续细化后，将结构建议实现为独立C#原型：个人身体目标＋临时互动偏移，不更新自身status，不读取对方隐藏status。不合入Unity，不改共享空间控制器和阈值。

当前完成可运行函数、初始参数及可见量单向回放；未完成身体反馈闭环、动画自然度或地位感知验证。数值已明确，但都是可否决的初始选择。

## 1. 自己的表达基底

`b(s)=(1-s)*CompactAtStatusZero+s*CompactAtStatusOne`

s是自己的status，c∈[0,1]是紧缩修改目标：0为原动作，1为允许的最大收缩。当前SourceToCompact端点为1、0，即b=1-s。仍是未经感知标定的线性创作假设，原动作也不代表社会中性。本轮不以任意曲线替换后宣称更合理。

## 2. 对方可见身体的线索

每个邻人只有ID、可见E/H、水平相对位置/速度和测量置信度。先按ID分别以τ=.45秒低通E/H，再计算：

`E=dot(leftShoulder-leftElbow,rightShoulder-leftShoulder)/shoulderWidth²`

这是冻结reference中的左肘展开几何公式，独立计算，不覆盖共享ObservedExpansion。只描述左臂，不等于完整双臂占用空间；没有沿用共享`.05/.7`映射。

`H=(hips.y-mean(leftAnkle.y,rightAnkle.y))/mean(leftLegLength,rightLegLength)`

腿长为股骨＋小腿骨段长度。H是相对踝部的可见胯部高度，不是人物身高或脚底地面高度；上下坡、跳跃及脚抬起可能混淆，当前只诊断两个原有地面运动片段。

`zE=(E-E0)/Es; zH=(H-H0)/Hs`

`D(z)=sign(z)*max(0,abs(z)-.10)`

`q=.6*tanh(D(zE))+.4*tanh(D(zH))`

q∈[-1,1]，正值表示相对参考更展开/更高，负值表示更收缩/更低；不命名为“估计出的对方status”。.6/.4是未验证的组合权重。连续死区减弱小变化，tanh限制极端值，均不单独保证完整反馈稳定。

参考来自M01/M07未修改源动作的298个过滤后样本，排除启动前.5秒。中心取中位数，尺度取max(p90-p10,人工下限)：E0=.2547954751、Es=.10、H0=.9393745411、Hs=.04。两个尺度均落在人工下限，不是充分数据标定。校准与诊断使用同样片段，无留出验证或地位标签。[参考数据](../../outputs/individual-expression-candidate/visible-reference.json)。

## 3. 相遇权重

r为水平相对位置，v为相对速度，d=|r|，接近速度u=-dot(r,v)/d：

`tCPA=clamp(-dot(r,v)/max(dot(v,v),1e-8),0,1.8秒)`

`m=|r+v*tCPA|`

S(a,b,x)表示a至b之间的三次smoothstep：

`rawWeight=[1-S(.8,3,d)]*S(.02,.30,u)*[1-S(.8,1.6,m)]*confidence*warmup`

距离、预测最近距离用米，接近速度用米/秒。confidence裁剪到[0,1]，由宿主根据测量提供，不能用对方隐藏设定。warmup=1-exp(-本次相关观测时长/.4秒)。非法、重合退化、3米外、平行及离开者权重为0。

首版仅响应接近中的相遇：站着不动即使很近也不响应，尚不是一般性近身互动模型。预测最近距离用于选择相关相遇，不修改导航或决定通过顺序。单向回放给定1米距离、.5米/秒接近的观测输入，不冒充实际模拟轨迹。

多人时`w_j=rawWeight_j/max(1,sum(rawWeight))`，总权重≤1，远处总影响小时不放大到1。自身ID、重复ID及非法测量不参与。失效/退出对象清除各自观测滤波状态，避免跨对象污染。

## 4. 有界临时回应

`a(s)=.5+.5*(1-s)`

`desiredOffset=.15*a(s)*sum(w_j*q_j)`

本轮选择“对方更展开/更高→自己稍收缩；对方更收缩/更低→自己稍展开”作待测方向。方向、.15幅度和a(s)的地位依赖均是创作假设，尚未比较同向回应、反向回应与不回应。高status仍有至少一半响应幅度，配合不会改变自身设定。

.15是紧缩目标区间的15%，不是身高、角度或社会地位的15%。始终围绕固定b计算，不累加到status。b=0/1处可能裁掉一个方向的响应，输出Saturated记录它，不暗中平移个人基底。互相这样回应仍可能放大差异，完整身体→可见量→回应灵敏度尚未测定。

## 5. 时间更新与身体执行

有相关观测时τ=.35秒，否则释放τ=.6秒：

`step=(desiredOffset-offset)*(1-exp(-dt/tau))`

`offset=clamp(offset+clamp(step,-.4*dt,.4*dt),-.15,.15)`

`cTarget=clamp(b+offset,0,1)`

偏移速率最多.4目标单位/秒。失去邻人后逐渐回到个人基底。关闭互动开关会清除偏移并立即输出个人基底，全身体表达总开关另行控制。

新增`ExpressionPolicy.StepCompactness(cTarget, profile.MaxLoweringFraction, bodyScale, rootSpeed, dt, enabled)`直接消费目标，不反算虚假ownStatus。旧Step接口保持数值一致。身体层原有τ=.20秒平滑、速度调节、9°上臂上限与高度预算仍生效，cTarget不是立即达到的骨架状态；双重滤波延迟待测。

互动模块不执行高度IK。IE-03膝部连续性风险仍存在，不能由标量检查覆盖。未来宿主须先获取所有人同一轮最终可见骨架快照，再统一计算目标，避免新旧姿态混读。
