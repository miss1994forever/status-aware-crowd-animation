# 互动表达：防止震荡与反馈放大

2026-11-05。用户提出自身设定＋对方可见动作＋距离共同影响表达，并进一步要求避免震荡/放大。这里给出具体控制结构与独立压力模型；尚未接入角色、身体组合求解器、导航或Unity，不把标量模型稳定当成动画效果成立。

## 风险来自完整回路

链条为 A表达→A可见身体→B观测/映射→B表达→B可见身体→A观测/映射→A表达。仅把λ设小、把数值夹到[0,1]、降低更新频率或加滤波，均不能单独证明此回路稳定。

可能出现持续交替、不断增加差异直到幅度上限、步态周期被误当社会变化、切换邻人导致跳变。两边最终停在极端值也可能是不希望的放大，不应只用振荡次数判断。正常源摆臂的周期性和受外部事件驱动的变化，不等于控制器自激振荡。

## 建议的最小结构

1. **固定基底＋有界临时偏移。** 每次重算 target=ownBaseline+boundedInteractionOffset，不把delta不断累加到自身status或上次表达。不建立跨相遇关系记忆。互动结束后偏移回零，保留个人表达。
2. **完整回路敏感度预算。** 映射连续且斜率有限。限制最大幅度同时检查“角色表达变化多少，会让对方下一次表达变化多少”。当前`.05/.7`观测映射、身体编辑与离散组合选择都在预算内，不能忽略身体→观测这一段。本线不自行改共享阈值。
3. **多人总影响受限。** 若采用多个邻人，则w_ij=rawWeight_ij/max(1,sum(rawWeight_ik))，sum(w)<=1；远处总权重小于1时不重新放大成1。rawWeight含距离衰减、几何相遇相关性和可见线索置信度，不能读别人隐藏status。若只保留一个几何相关对象，则不要在最近者之间逐帧切换。
4. **观测与表达分别平滑。** 只平滑表达参数，保留源动作节奏。速度上限按秒定义，不按帧硬编码。平滑是辅助，不代替回路敏感度限制。噪声需要时采用连续死区 sign(e)*max(0,abs(e)-epsilon)，避免“过门槛突然跳到某强度”的硬阶跃。
5. **对象绑定与退出。** 同一对象的短时滤波状态绑定ID；换人清除旧观测，表达偏移通过短暂渐变重新连接。相遇权重进入/退出可使用滞回，防止边界反复开关；低置信度回到中性响应。此为几何互动状态，不新增注视/转头模块。
6. **统一快照与预算。** 所有人从同一轮快照读取可见量，再一起产生新目标；避免更新顺序导致后更新角色读到“本帧新值”。延迟仍要实测；一致快照不等于没有反馈或天然稳定。

首轮保持导航和身体表达的调节职责分开；身体表达的稳定不代表空间规划回路稳定，反之亦然。下一步只能串行打开闭环，不能同时改姿态、观察公式和空间阈值后宣称因果清楚。

## 有条件的数学依据

冻结源姿态、环境、对象选择和外部输入，令完整的同步、无记忆响应映射为F(c)。若在允许区域内满足无穷范数 Lipschitz界 L<1，并且输出仍在该闭区域内，则F是收缩映射，具有唯一固定点。其数学依据见[康奈尔大学固定点迭代讲义](https://www.cs.cornell.edu/courses/cs4220/2026sp/lec/2026-03-27.html)。该讲义不是status研究。

对于c_next=(1-beta)c+beta*F(c)，0<beta<=1，由三角不等式可得变化放大上界(1-beta)+beta*L<1。这是本项目对该结构的直接推导。**如果L>=1，单靠减小beta不能从这个条件获得保证；也不意味着每种这种系统一定不稳，此条件充分而非必要。**

对多角色，可用各行绝对敏感度之和的上界来限制F的无穷范数L。必须包含身体到观测的变化率；只限制r函数的斜率不够。实际Bodies有相位、滤波器、延迟、目标切换和导航几何，以上冻结无记忆条件不直接成立；需要分析扩展状态或做有边界的实测。数值扰动可发现问题，有限采样不能证明全域上界。

## 离线压力模型与实际结果

独立脚本 `src/individual_expression_candidate/audit_feedback_loop.py` 使用已知人工观测q=clip(.5-G*(c-.5))，回应λ*tanh(k*(q-.5))，.4秒观测滤波、.3秒表达滤波、.25秒延迟。所有值和时间常数都是控制结构的演示设定，不是经过status/自然度标定的参数。

- λ=.45、k=10、G=1：加入两个滤波仍出现持续振荡，末6秒峰峰值约.46。
- λ=.15、k=2、G=1：人工瞬时敏感度界.3，两种起始条件均收敛；30/60/120fps例子均通过。
- λ=.15、k=10、G=4：幅度较小但人工映射很陡，仍出现约.19峰峰值波动。
- 高敏感度、反向初始差异：可以停在明显分化的极端，而非振荡；低敏感度对应例子回到同一结果。
- 两个人基底为.35/.65时，互动产生临时偏移；12秒退出，偏移消失并返回各自基底，不改写基底。
- 输入1.8Hz/.03幅度噪声时，低敏感度例子保留小幅受迫波动，不能声称所有波动都被消除。
- 10人使用总权重预算，人工瞬时界仍约.3；两种初始状态24秒后的差异约机器精度。没有碰撞、导航、真实骨架和可见几何，此例不继承为十人工程验收。

## 进入真实身体前的关卡

先冻结身体表达与几何位置，单向播放已记录的可见量，检查响应范围、步态波动和切换；再做双向固定位置测试，测完整映射的扰动传播；之后加入距离变化、对象切换、观测缺失、帧率变化和互动退出；最后才打开空间反馈和十人。保留原版开关，按身体表达/互动偏移/导航分别记录。

记录持续振荡幅度、饱和占比、目标切换、离开后的残余偏移，以及受到相同外部输入的两个不同初始状态是否持续分化。不能只记录“参数在[0,1]内”。如观察不可靠、持续振荡或极端固化，关闭互动偏移，保留个人表达与已验收空间版本。
