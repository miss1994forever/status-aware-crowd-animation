# IE-02：源运动参照的协调表达算法

2026-11-05。用户授权继续推进算法。本次选择持续个人表达作为首轮主机制；相遇中的事件表达不另开发，继续由既有空间线承担响应。下面是可实现、可否证的首版，不是通用status公式，也不要求高地位始终先行。

## 自主机制与研究假设

算法将角色创作设定转成源运动参照的身体目标，再按运动状态和局部姿态限制编辑幅度。不是更换动作标签或对某一个动画做固定手工修正。

依据：旧打招呼的高度＋左臂组合得到过有限地位反馈；单臂更像不自在，前倾带来疲惫/邋遢印象，固定夸张肘位曾被认为不自然，C迁移偏羞怯。因此首轮只保留有限高度＋上臂展开的目标，不加躯干前倾、昂头、步速变化或额外头部动作。双侧弱调节替代固定单侧是新的工程假设，不能继承原单侧实验结论。

表达映射由 `ExpressionProfile` 明确给出两端：status=0时的compactness、status=1时的compactness、最大降低/身体尺度。首个实验配置 SourceToCompact=(1,0,.0125)：高端保留源动作，低端朝较紧凑目标。它是从已有反馈选出的一个**源动作相对假设**，不是低地位本质上等于收缩；不同基础动作之间也不保证相同印象。Neutral=(0,0,0)作为独立消融。策略/几何分离允许后续替换映射，而不重写姿态编辑器。

## 连续策略

自身status `s` 裁剪至[0,1]，按作者配置作线性插值 `c=(1-s)c0+s*c1`。不假定真实社会等级是等距量表，此处只定义创作控制柄。

速度比 `v=rootHorizontalSpeed/bodyScale`，单位为身体尺度/秒。机械适配 `g(v)=(.65+.35*smoothstep(.05,.35,v))*(1-.35*smoothstep(.8,1.6,v))`。它只用于停走/快速时减弱叠加，不表达“走得慢就地位高”。系数未经感知标定。

同一指数状态 `w += (c*g(v)-w)*(1-exp(-dt/.20))` 驱动两个通道：手臂权重w；高度请求 `bodyScale*.0125*w`。约1.648米身体尺度下满幅约2.06cm，只与历史幅度相近，不是身高/地位生理公式。高度请求和上臂幅度相关联，但局部约束可以削弱实际执行，两者不保证最终相同强度。

`ExpressionPolicy.Step` 不接收邻人status、通过顺序或导航优先级。`ExpressionOverlay` 不再接收status，只接收经过策略计算的命令。不是在编辑器内暗中把角度当地位值。

## 姿态求解与约束

上臂算法延续IE-01的局部坐标、原姿态驱动、定长圆弧、向下手臂/大摆幅的平滑退出；上限9°，保留上臂向量前后分量，不主动跨越肩内侧。每帧从新鲜源骨架计算；不累加上次修改。左增益1、右.75，是待测值。没有全身动力学或末端接触保证。

高度通道只返回请求。宿主可调用 `command.BoundedLowering(capacityMetres)` 限制实际降低；capacity必须由负责腿部的宿主提供，默认0。此函数只作标量裁剪，**不是几何可达性证明、不是腿IK**。宿主还必须保证该预算的时间连续性，调用其已验收的脚/膝策略。不能直接把全部请求写入髋部就声称脚部已受保护。

优先级：源运动和宿主约束优先于表达。高度不可用时不把缺失幅度转移到手臂，也不提高夹臂补偿。应记录执行不足；此时只能评价手臂消融，不能宣称完整组合通过。

## 首轮已经产生的证据

真实代码静态编译；数学/策略约束检查通过。回放使用本地已冻结M01向前行走195帧和M07侧移135帧，逐帧原FK，不采用旧闭环改动，原生采样间隔。 source/fixed/half/full共享每一原帧、时间、腿部和根轨迹。回放内调用实际C#策略和数学核；骨架子树旋转是离线重建，不能替代Unity适配器运行。

此轮只应用上臂通道，高度请求保留在JSON，未修改髋/腿。源坐标为旧冻结参考身高单位，原BVH物理单位未确认；回放使用bodyScale=1和同单位速度，仅检验无量纲一致性，不虚构米制测量。

两个原片最大骨长误差约6.2e-16参考身高，非手臂关节改动0，前后分量变化0；最大上臂修正8.98°。手腕最大位移约.053参考身高，仍须检查人体网格与手部附近接触。观察量最大改动约.177，不能沿用旧belief/response实验结论。

## 评价与停止

原运动、旧固定规则、新算法同输入对照用于审查机制；旧12°与新9°并非等幅，因此不构成“姿态适配单独有效”的因果证明。首轮不继续增加匹配参数扫描。新算法端点/中点供控制连续性诊断，不能当两个人类地位真值。

先看自然度和自由描述，再分别判断地位、害羞/不自在、自信、威慑和疲惫。若只显得害羞，则报告该映射地位意义未通过；若变化不可读或更怪，停止优化并保留自然版本。只有手臂通过后，才由空间线排队检查高度组合、脚膝、网格及最终观察信号；再开互动，最后群组验收。今晚提交冻结优先于继续探索。
