# IE-04：双向离线骨点反馈检查

2026-11-05。用户要求继续后，把之前单向可见量回放推进到双向反馈。不是Unity运行，不修改共享空间代码。

## 实际接上了什么

每个角色执行独立InteractiveExpression → ExpressionPolicy.StepCompactness → 原离线身体求解 → 新骨点E/H。对方下一轮只读取这些输出骨点算出的E/H，不能读取自己的作者目标、身体权重或隐藏status。所有角色从同一份不可变快照读取，随后统一更新身体；观测延迟额外作用在骨点快照上。

手臂使用真实ExpressionMath，组合使用真实BodyCombinationSearch以及IE-03离线重放的同一Make函数。只把该测试函数与返回类型开放为internal供测试复用，没有修改其几何逻辑。腿部仍是只读SprintLegIK快照＋原有managed UnityMathShim；不代表与Unity引擎等价。

保留原来两段源片M01/M07，使用声明的虚拟1.65米尺度。它只给工程阈值提供单位，不是源BVH演员的实测身高。脚部回到输入骨点不是人体网格接触保证。

## 场景及判据

每次正式反馈24秒，先用3秒相反的可见信号预置两种有界历史；之后未来输入相同。这个比较只能检查两种初态，不能覆盖所有初态。

18种场景，每种两次历史：

- 两段源片各固定在第40帧，分别使用手臂或组合，额外延迟0/.25/.5秒，共12种，60fps，双方status=.5。
- M01组合另检查30、120fps，延迟.25秒，共2种。
- M01组合在12秒退出互动，双方status=.2/.8。
- M07循环原动作＋给定相对轨迹r.x=3-.5t，双方status=.2/.8。接近、经过、离开由该外部轨迹驱动，不是导航结果。
- M01循环原动作＋冻结相遇上下文，双方status=.5。
- M01固定组合，双方status=0/1，检查端点裁剪。

固定姿态测试**冻结接近瞬间的相遇上下文**：1米距离、.5米/秒接近。不是声称固定位置的人实际仍在接近，也不是“站着也会回应”的功能修改；首版真实门控仍会排除静止者。

循环源动作按原始dt取最近帧、重复原片，未修复循环缝；步态及循环缝是外部驱动。不能把这类周期变化当成自激震荡，也不能据此评价动画连续性。

数值判据预先设置为1e-4：末3秒两种历史的目标/手臂权重/高度差异小于该值；固定姿态的目标、手臂权重、高度峰峰值也小于该值；退出场景另看末段偏移残余。高度单位为参考身高，其他量无量纲；这是工程检查阈值，不是感知阈值。移动片段不要求参数停止变化。

逐帧检查回应有效、总权重≤1、偏移≤.15；组合必须可行，骨长误差<4e-5虚拟米、足骨点误差<1e-12米、股骨方向相对源修改≤12°。这些条件不证明膝盖轨迹自然，IE-03的膝部连续性风险仍保留。

另外用相同历史独立运行正序/逆序更新，检查目标输出一致；不同历史的两次运行不能用于单独判断更新顺序影响。

## 输出及复现

实测结果：18/18种场景通过上述数值判据，共302529项逐帧约束检查；相同历史下反向更新的目标差异为0。不同初始历史的末段目标差异最大约2.08e-8，退出场景偏移残余约6.84e-9。最大骨长误差约9.71e-6虚拟米，最大股骨方向修正约10.71°，没有组合平滑回退。

在固定源姿态测试中，没有观察到持续参数震荡。循环M01时末段目标峰峰值约.01484，两种历史末段目标差异约1.40e-8；该例有周期外部输入，不能据此宣布完全消除了自激、放大或步态干扰。

**数值通过不等于互动功能通过：M01第40帧、status=0/1的端点场景，两种预置历史最终都停在1/0，有效互动偏移为0。** 第一组历史中双方全程饱和；第二组初期仍有偏移，之后也达到边界。审计saturationFraction取两次运行中的较大值，数值1不能解释为两组都全程饱和。虽然内部偏移有值，最终目标仍被裁剪。在该方向/姿态下，个人基底占满目标范围，互动无可用余量；这不是所有姿态和回应方向都完全失效的结论。

下一项设计修正应显式比较如何分配个人表达与互动余量。一个可审查的候选是`b_h(s)=h+(1-2h)*(1-s)`，h=.15时个人基底变为.85至.15，给两侧预留.15；代价是个人目标跨度从1缩为.7，必须重新看个人差异是否足够。另一条路线是扩展身体目标范围/通道，但当前只做源动作到收缩的执行器并不支持直接向外扩展。**本轮没有暗中应用任何一种修正，现有profile与五函数参数未变。**
