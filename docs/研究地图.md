# 研究地图

本页用于把问题拆成层次，防止在概念尚未明确时直接选择参数或模型。

| 层次 | 核心问题 | 可能证据 |
|---|---|---|
| 概念 | 要表达的是 status、dominance、prestige、personality，还是互动风格？ | 理论与综述 |
| 行为表达 | 现实或表演中，人们实际产生了哪些动作差异？ | 动作捕捉、行为编码 |
| 观察者感知 | 观众依据哪些线索判断人物及其关系？ | 用户实验、心理学研究 |
| 互动机制 | 一个人的行为怎样改变另一个人的后续行为？ | 双人实验、时序模型 |
| 群组涌现 | 多个局部互动怎样形成整体群组结构？ | 多智能体模拟 |
| 动作生成 | 怎样把决策转换为轨迹、姿态和连续骨骼动画？ | Steering、Motion Matching、IK、生成模型 |
| 评价 | 怎样判断结果自然、可控、多样并且能传达预期关系？ | 定量指标与感知实验 |

## 技术光谱

| 方向 | 规模 | 细节 | 当前成熟度 | 主要限制 |
|---|---:|---:|---:|---|
| 导航与避障 | 高 | 低 | 高 | 容易显得机械、同质化 |
| 异质人群参数 | 高 | 中低 | 中高 | 个体差异常被简化为随机参数 |
| 小群组行为 | 中 | 中 | 中 | 群组形成和互动评价较难 |
| 双人反应生成 | 低 | 高 | 快速发展 | 数据和模型通常限定具体动作类型 |
| 全身多人生成 | 低到中 | 高 | 研究阶段 | 接触、穿透、长期一致性和算力 |

## 当前值得关注的研究空隙

传统人群模拟擅长“很多角色如何移动”，互动动作生成擅长“少数角色怎样具体互动”。两者之间的中小型群组仍可能存在空间：在可实时运行的约束下，使局部关系影响轨迹选择和身体反应，并验证观众能否感知这些差异。

这只是需要文献验证的方向判断，不能直接视为创新结论。
