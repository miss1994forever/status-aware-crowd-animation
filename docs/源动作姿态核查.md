# M01–M03 源动作核查（2026-10-24）

## 结论与行动

1. 发现并修正了旧预览的位移读取约定问题：Bandai 六通道关节的位置值已经是局部位置，不应再把 OFFSET 加一次。旧实现使本次检查的身体骨段长度约为正确值的 2 倍，而角色前进距离没有同比放大，会影响步幅／脚滑判断。
2. 原始 BVH 没有改动。旧网页已保留于 `outputs/preview-before-translation-fix/index.html`，修正后的预览仍为 `outputs/preview/index.html`。
3. 修正并未消除 M02 的相对后倾、M03 的持续屈肘与较小手部摆幅；它们在按源数据约定重建的坐标中仍存在。不能把所有违和感都归因于播放器，也不能把本次几何量直接当 status 参数。
4. 暂不进行肩部／手臂风格修改。先推进可靠坐标下的循环、路径与身体运动，再用保留原版的对照让用户选择表达素材。

## 为什么调整读取约定

- [数据作者的参考可视化脚本](https://github.com/BandaiNamcoResearchInc/Bandai-Namco-Research-Motiondataset/blob/master/utils/blender/convert_bvh2mp4.py)使用 Blender 的 ARMATURE BVH 导入，而非作者自定义的位移叠加。
- [Blender 官方导入实现](https://github.com/blender/blender-addons/blob/main/io_anim_bvh/import_bvh.py)在动画位置处理部分用通道位置减去静态局部头部偏移，再在骨架中应用。这与本批数据“平移通道替代对应 OFFSET”的解释一致。
- [早期 BVH 格式说明](https://research.cs.wisc.edu/graphics/Courses/cs-838-1999/Jeff/BVH.html)讨论了根平移加偏移、其他关节仅有旋转的常见布局；不能直接据此断言本批所有非根六通道关节都应累加。

这是阅读作者使用方式、参考实现并结合原始数据作出的工程判断；没有在本机安装／运行 Blender 来逐帧比对作者渲染。项目算法依然自主实现，没有复制 Blender 代码。

`Motion.positions` 现在显式区分 `offset_plus_channels`（保留旧行为以兼容已有调用）和 `channels_replace_offset`（当前 Bandai 数据使用）。构建原预览与新原型时必须明确使用后者；不能依赖默认值。无位置通道的轴与末端仍保留 OFFSET；替代模式不接受位置旋转交错，避免对未验证格式静默猜测。

原测试验证了实现与既定叠加模型一致，却没有发现数据约定选错。因此“测试通过”不等于“模型解释正确”。新增测试覆盖实际 M01 首帧 Hips 坐标与骨长，且生成网页的测试检查正确模式。

运行 `python3 scripts/audit_pilot_posture.py`，结果为 `outputs/posture-audit/audit.json`。源文件 SHA-256 与 manifest 一致；M01/M02/M03 分别检查 195/331/481 帧，共 1007 帧。

- M01 首帧 Hips 从错误的 `(-1.71443, 184.1945, -410.123)` 改为源通道位置 `(-1.71443, 90.2704, -407.123)`。
- 同帧 Hips→Spine 长度约 15.7357 源单位，而非 31.4714；没有据此宣称源单位是厘米。
- 独立编写的四元数递推与矩阵 FK 在这三段全部帧中最大坐标差约 `1.14e-13`。这是算术交叉检查，不是第三方渲染器验证，也不能单独验证数据语义。
- 身体骨段旧／新长度比的中位数与 P05/P95 均约 2；排除了合成根与零长末端。

### 描述性几何，不是心理标签

下表用全片统计。倾角按髋→颈方向相对竖直轴计算，在该片净运动方向上前倾为正；屈肘以完全伸直为 0°。手部前后摆幅为相对髋的前向位置 P95−P05，除以该片固定的中位头脚高度，仅用于无量纲比较，不作用到动画。

中间 80% 帧的躯干倾角中位数依次约 −1.01°、−4.61°、+10.05°，方向趋势未依赖首尾少数帧。M03 的手相对髋部更高且维持在身体前方；但不是“完全不动”。

因为旧错误主要成比例放大骨段，上述角度和身高归一化量修正前后几乎一致。这解释了为何修正尺度后，原来看到的姿态区别仍然存在。躯干后倾不等于肩关节后收；本次没有精确定位用户所说的肩部违和到单个关节。

## 证据边界

- 没有从这三条轨迹估计 status，也没有评价“高 status 必须后仰”等规则。
- 用户首次反馈对应修正前预览，应保留这个版本上下文；姿态比例近似一致也不能代替新版本复看。
- 净行进方向仅适合本次直行片段的描述，不能直接用于转弯、倒走或侧走。
- 原样片自身循环接缝仍未处理；新路径原型另做相位选取与循环构造。
