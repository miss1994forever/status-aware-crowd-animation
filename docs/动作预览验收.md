## 启动

在项目根目录执行（Python 3.10+，无第三方 Python 依赖）：

```sh
python3 scripts/build_motion_preview.py
```

打开 `outputs/preview/index.html` 即可使用；文件已包含全部 12 段的关节坐标、界面、播放器代码，没有 CDN、远程字体、外部脚本、fetch 或模块加载。原始 BVH 仅构建时需要，播放时无需 Python 或网络。初次生成需要本地已有 `data/pilot_manifest.json` 与 12 段源 BVH；本任务没有重取或修改数据。

macOS 可在访达双击 HTML，或执行：

```sh
open outputs/preview/index.html
```

备用启动方式（本次实际测试使用）：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory outputs/preview
```

浏览器访问 `http://127.0.0.1:8765/`；不需要外网。Ctrl+C 停止服务器。端口被占用时可换其他本机端口。

**验证边界**：浏览器工具只允许 HTTP/HTTPS，拒绝 `file://` 协议，因此本次没有实际完成双击 HTML 的运行验收；未尝试绕过该限制。离线自包含性由打包结构测试验证，实际渲染与交互由本机 HTTP 页面验证。建议主聊天或用户再用访达双击检查一次。

## 功能与操作

- 左侧 M01–M12 对应清单原顺序，切换动作回到首帧，保留播放/暂停状态。
- 播放/暂停、时间拖动、0.25/0.5/1/2 倍速、循环开关、回到首帧。
- 斜视、沿 +Z、沿 +X、俯视 +Y；拖动画面可自由旋转；左右肢体用不同颜色区分。
- 默认跟随髋部的水平位置；取消后按全段轨迹范围取景。均保留源关节坐标，不执行原地化。
- 先点击画面，再用空格播放/暂停，左右方向键逐帧。时间滑条获得焦点时保留浏览器原生方向键行为。
- 默认隐藏原始风格名；取消复选框后显示 normal、proud、not-confident。内容类别与中性编号仍可见。隐藏标签仅改变可见界面，源数据仍在 HTML 内，顺序固定，不是严格盲测。

## 动画变换与时间约定

`src/bvh.py` 增加 `Motion.positions(frame)`、`duration`、`frame_at(seconds, loop)`，保留原解析与统计接口。采用列向量，关节局部矩阵为：

```text
local = T(OFFSET) × C1 × C2 × … × Cn
world = parent_world × local
position = world × [0, 0, 0, 1]
```

所有通道按文件声明顺序相乘，旋转角由度转弧度；父节点先于子节点计算；所有关节的 position 通道都参与；End Site 也继承完整层级。测试专门使用非交换旋转和旋转/平移交错排列，避免“解析保留顺序、计算却忽略顺序”。

这些源 BVH 含额外根 `joint_Root`、Hips 及多处与 OFFSET 近似相同的 position 数值。本工具按 OFFSET 加通道变换逐项解释，不擅自删掉重复值、归零子节点平移或重新估计骨长。根到 Hips 的辅助连线不作为人体骨段绘制，计算仍保留根变换。部分末端偏移为零；头部圆圈是辅助标记，不是重建出的头部网格。

播放使用源文件约 30 Hz 的记录帧，逐帧保持，不做插值。总播放时间为 `N × frame_time`，最后一个采样帧也保持一个采样周期；第一帧到末帧采样时刻为 `(N−1) × frame_time`。开启循环后按总时长回绕；关闭循环后停在末帧。由浏览器单调时钟推进，页面重新可见时重置时间基准，不补播隐藏期间时间。

## 坐标轴、尺度与真实数据结果

12/12 SHA-256 与既有清单一致，全部 **3,014 帧、约 100.4665662 秒**完成 FK，所有坐标有限，每帧 27 个节点，源数据仍为 22 个动画关节、132 通道。

数字检查与实际画面均支持当前 Y 向上的显示选择：髋部高度变化仅约 2.4–5.6 个源单位；主要行进发生在 X/Z 平面，沿该轴显示的人体站立，四肢关节连接可见。地面仅放在全段人体节点的最低采样 Y，不是已估计的接触平面。

物理单位仍**未确认**：BVH 与本地来源说明均未声明单位；本工具不标厘米或米，不以人体先验反推单位。M01 人体全段 Y 范围约 9.95–281.37，数值是按上述矩阵约定得到的源单位范围，不是经校准的人体身高。尚未与原作者独立播放器逐关节比对，重定向前应再核对作者导出约定和物理尺度。

## 已知限制与下一阶段边界

这是正交投影的三维关节线框检查器，没有蒙皮、光照、透视相机、IK、重定向或接触修复。循环接缝可能位置/姿态跳变，未自动拼接或原地化；地面和头圈是显示辅助。未测定物理单位；未与作者渲染器独立对齐；未量化脚滑、自然性、浏览器性能或跨浏览器兼容性。视角名称使用源坐标轴方向，不能将沿 +Z 自动称为所有片段的角色正面。

未实现 status 行为、多人系统或 EMM。风格名不代表地位标签。隐藏标签和播放截图不等于感知实验通过。
