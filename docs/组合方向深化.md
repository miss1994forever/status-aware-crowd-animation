# 组合方向深化

## 暂定研究结构

当前值得继续讨论的组合是：

> 以动态的非语言 status 互动为研究核心，以环境感知 Motion Matching 作为全身动画表现层，使角色在观察和回应彼此动作的过程中形成可被观众感知的相对关系。

这仍是候选结构，不代表题目、参数和具体算法已经确定。

朋友、家人、同事等社会关系不再作为核心建模目标。它们至多是影响互动的情境条件；即使两个角色是陌生人，也可能在争夺路径、空间或行动主动权时形成暂时的主导—退让关系。

## 系统分层

```text
场景与创作者输入
  ├─ 环境、目标、紧迫程度
  └─ 任务、情境角色与可选的背景关系
            ↓
动态 status 互动层（主要研究对象）
  ├─ 发现局部互动对象
  ├─ 表达当前的坚持、试探或退让
  ├─ 根据对方近期动作形成暂时判断
  ├─ 产生互补、抵抗或模糊回应
  └─ 让相对关系逐渐稳定、持续协商或发生反转
            ↓
连续目标轨迹
  ├─ 未来位置与朝向
  └─ 平滑、预测与防止来回震荡
            ↓
全身动作表现层
  ├─ Environment-aware Motion Matching
  ├─ 环境和其他角色碰撞惩罚
  └─ 从已有动作数据库中选择连续姿态
            ↓
结果与评价
  ├─ 碰撞、通行、等待和群组保持
  └─ 观众能否看出预期互动差异
```

## 对 EMM“动作风格”的准确理解

EMM 的风格示例把新的动作捕捉数据替换进数据库。论文展示的角色平时抬起手肘、占据较大空间，但在接近其他角色时选择更紧凑、更安静的姿态。

它可以被观众理解为谨慎或害羞，但算法本身没有定义或推理心理学意义上的“害羞”。它解决的是：

- 数据库中已经存在不同姿态；
- 环境约束使某些姿态比其他姿态更合适；
- Motion Matching 自动选择更合适且连续的动作。

因此，如果希望不同角色有不同动作风格，动作数据库必须包含相应动作，或使用不同数据库/动作子集。EMM 不能从没有见过的动作中凭空创造一种新人格。

## 多人物能否保持 EMM 的动作质量

原则上可以让多个角色分别使用 EMM。论文也展示了多人通道和基础 crowd steering 集成。单个角色的动作质量主要来自动作捕捉数据和 Motion Matching，因此人数增加不会必然让每个人的动作变差。

真正的限制包括：

1. 每个角色都要进行动作数据库搜索，计算量随人物数量增长；
2. 如果所有角色同时改变目标轨迹，容易出现互相反复避让、僵持和震荡；
3. 上层决策给出的轨迹若突然跳变，Motion Matching 也无法保证自然；
4. 动作数据库覆盖不足时，系统只能选择最接近但不一定合适的姿态；
5. 当前 EMM 不保证严格无碰撞，且不处理握手、推挤等需要精确双人接触同步的动作。

论文在密集障碍压力测试中报告：最终方法一次搜索平均约 0.80 ms，搜索每 10 帧执行一次，运行于 CPU 单线程；这一结果来自作者测试环境，不能直接等同于 M2 性能。多人实现可以通过错开不同 agent 的搜索帧、降低远处角色更新频率和动作层级细节来控制开销。

## 建议的渐进实现规模

规模不作为题目参数预先锁定，而作为逐级验证目标：

1. **2 人**：验证关系决策能否稳定地产生不同的坚持/退让结果；
2. **4—8 人**：验证多个局部互动、小组等待、分裂和重组；
3. **更多角色**：根据 M2 实测性能决定是否使用动画 LOD，近处角色使用完整 EMM，远处角色使用简单 locomotion。

研究成功不要求所有角色在同一时刻进行复杂接触。非接触或弱接触的经过、等待、侧身、跟随、分离和重组更适合当前技术路线。

## 可能的核心创新问题

以下问题仍需通过文献和原型比较，不能同时全部选择：

### A. 动态 status 协商

角色能否只根据彼此可见的近期动作，而非直接读取对方隐藏属性，逐步形成可辨认的主导、退让或平等关系？

### B. status 的全身动作可读性

轨迹选择、反应时机、身体朝向和空间占用怎样共同表达互动关系？仅改变轨迹与同时改变全身动作相比，观众判断是否不同？

### C. 局部互动组成的多人场景

许多短暂的双人或三人 status 协商，能否在中小型场景中形成多样但不随机混乱的群组动作？

## 当前最重要的技术边界

- status 表达、观察、回应和关系更新由本项目研究；
- 社会关系、正式身份和人格只作为可选背景条件，不与互动 status 混为一谈；
- EMM 负责把平滑目标和空间约束转成已有数据库支持的全身动作；
- 暂不把精确身体接触、物理推挤、自动生成新动作风格或大型深度模型训练作为第一阶段目标；
- 如果后续确实希望表现推挤，可以把它作为独立的近距离互动状态，使用专门动作片段或物理响应，而不是要求基础 EMM 自动产生。

## 2026-10-15：动态 status 的建模选择空间

下一步不应先规定“高 status 角色的速度、姿态和距离参数”，而应先决定系统究竟在模拟什么。当前可比较四类模型：

### 1. 固定等级映射

每个角色具有固定等级，等级直接决定扩张/收缩、坚持/退让等动作。它实现简单、结果容易控制，但会把 status exercise 中最有意思的互动过程压扁成角色标签。适合做对照基线，不适合作为主要贡献。

### 2. 离散事件或状态机

把接近、阻挡、试探、坚持、退让、僵持和恢复做成状态及转移。优点是可解释、容易实现和导演；缺点是可能呈现为预先写好的反应脚本，连续性和意外变化较弱。

### 3. 连续的互惠动力系统

角色持续观察对方近期行为，并逐渐改变自己当前表达出的互动姿态。互补意味着一方增强坚持时另一方倾向退让；抵抗意味着双方暂时同向增强；历史、反应延迟和惯性使关系可以稳定、振荡或反转。这类模型最贴近“关系在互动中形成”，但需要避免数值振荡和难以解释的参数。

### 4. 目标与代价驱动的局部协商

角色不是直接选择“表现得高或低”，而是在保留路线、节省时间、避免碰撞、保持舒适距离和回应对方之间权衡。谁先让路、谁改变目标、谁持续占据通行权成为互动结果。它与课程中的路径规划、避碰和动画控制结合最自然，但如果没有全身动作与时间结构，容易退化为普通导航算法。

目前较有潜力的不是四选一，而是 **3 + 4 的混合**：

- 任务和环境制造一个真实的局部冲突；
- 连续互惠模型决定角色如何解释并回应对方；
- 局部规划把回应转成路线、速度和朝向；
- 动作表现层把这些变化变成可读的全身动作。

固定等级模型与纯避碰模型可作为实验基线，状态机可负责少量明确阶段，但不应让状态机完全替代互动生成。

## 先记录可观察现象，而不是先锁定参数

候选观察维度包括：

- 谁先提出行动、占据路线或迫使对方回应；
- 对方多久注意到并开始调整；
- 遇到抵抗后是坚持、试探、升级、绕开还是退让；
- 双方的轨迹、速度、朝向和空间占用怎样共同变化；
- 视线和头部是否表明角色确实注意到了对方；
- 一次结果是否影响下一次相遇，是否出现角色反转；
- 观众从完整过程得出的判断，是否不同于只看最终姿态或最终谁先通过。

这些目前是待观察和待验证的行为类别，不等于最终程序参数，也不应假设每个动作在所有情境中都有唯一的 status 含义。

## 暂定的最小研究单元

比起直接构建大规模人群，可以先研究一个可重复的“共享空间微互动”：两名角色的目标产生短暂冲突，双方必须在几秒内相互观察、调整并完成行动。例如同时到达窄门、交叉路径或汇入同一路线。

同一微互动应能产生多种时间过程，而不仅是不同结局：立即互补、短暂试探后互补、双方抵抗后由一方退让、僵持后恢复、以及多次相遇后的关系反转。随后再把多个局部微互动组合成 3—8 人场景。
