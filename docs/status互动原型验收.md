## 最终实现的接口与计算

`social.py` 的 `PrivateSelf(status)` 仅供本人表达；`VisibleNeighbor` 只导出id、位置、根朝向、可见运动方向/速度、实际局部骨架及停止标志。没有邻人目标、源动作编号、风格参考或未来计划。标号用于同一遭遇内关联观察，不参与权重与优先级。每个0.2秒决策周期先复制全体可见快照，所有人据此规划，再一起执行4个0.05秒子步。实际执行骨架重新导出为下一快照。理想化240°视野、2.5身高观察距离；没有图像骨架恢复或人/墙遮挡模型。

设邻人局部躯干倾角 `f=atan2(Chest.z−Hips.z, Chest.y−Hips.y)`。保留最近5次可见观察，少于3次时估计为None、置信0；否则 `e=tanh(mean(f)/0.16)`、`c=(1−d/2.5) exp(−std(f)/0.08) min(n/5,1)`。这是连续的工程代理，**不是经训练或感知校准的status分类器**。离开观察距离即清除对应临时历史，无跨次相遇记忆；仍在邻域但暂时转到视野外的历史可保留，尚未实现基于时间的遗忘。

另从左右上臂根节点的肩轴求实际躯干朝向，计算其与“邻人→当前观察者”方向夹角余弦 `a`，明确针对当前对象，而不是只看对方动画是否丰富。给各邻人权重 `w=max(0,1−d/2.5)` 和截断方位 `b=clip(bearing,−1,1)`：

```
g = 0.10 Σ(w b) / max(1,Σw)                         # 两条件共有的几何上身适应
s = 0.18 Σ[w b c (0.65 e + 0.35 a)] / max(1,Σw)   # C2额外社会通道
q_target = clip(g+s, −0.25, 0.25)
q_next = q + clip((q_target−q)(1−exp(−0.2/0.45)), −0.07, 0.07)
```

C1取s=0，但仍保留同样的动作库、上身自由度、完整几何适应和候选搜索。关闭社会通道与C1执行结果完全一致。取消置信调节的辅助版本仍需至少3次观察才有估计，但之后用c=1。各项参数以独立CONFIG保存；本轮选择的是小幅试探性映射，未指定高status必须抬头/抬肘。

自身私有实验值由独立随机数取±1，与M01–M03编号没有固定关系。共有个人表达层强度0.35只是工程起点，不是用户选定的最终比例；在其上施加±0.045rad的局部躯干俯仰假设。q控制Spine整棵子树相对骨盆的旋转，腿与根节点不跟着整体旋转来伪装表达。转换后的所有候选骨架进入原有1秒身体检查；同一个约束rollout用于预测和执行。相对原source的惯性偏差0.4秒衰减、定骨长、0.75rad骨方向偏离锥、8/12rad/s骨方向速率、地面投影都在共同适配层中。普通骨源相对锥不是生理学关节限位，支撑动力学和自然停止仍未解决。

导航使用只读原互惠速度建议、64候选预筛、相同动作/倍率/相位池、根yaw≤1.4rad/s、行进角≤1.8rad/s、标量变速≤1.2身高/s²。`navigation.py` 为原choose的显式适配副本，仅改为调用受限合成及附加源相对锥门槛；原模块未打补丁。完整身体占地仍要求1秒20采样点的间距≥0.015、厚度半径0.04、相对合成源最大变形≤0.4。没有按status修改通行权、避让圆、目标或优先队列；身体姿态会经实际安全检查间接影响路线。

失败时保留原紧急保持机制并记录，没有把保持改称自然等待。停止、到达保持会造成速度突变，不能引用活动步的速率限制将它们掩盖。执行候选无解时整个计划拒绝，没有隐性缩小身体或减少安全余量。

## 辅助yoked对照

在同一场景已完成的C2回放中，为每人选择另一人的遭遇信号。匹配只用遭遇持续比例、最近距离与最多可见邻人数；对齐首次观察时刻，按平方能量比例缩放，缩放限0.5–2。每个映射、时移、缩放、请求能量均保存于`data/status-interaction-lab/yokes/`。它是离线辅助构造，使用目标C2信号的能量进行幅度匹配，**不能当作在线模型或与主比较同等的因果证据**。当前几何、安全与执行仍在线，未复制骨架或伪造碰撞。

平滑、目标截断与无可行候选拒绝会使实际响应量不同。独立审计同时记录请求社会幅度、实际控制、拒绝量和身体差异；时序错配本身仍是自然性混淆。因此不以yoked更差（若出现）单独证明“理解了别人”。

## 检验的含义与尚未完成的验证

固定可见输入改变邻人的隐藏目标/参考/编号元数据/额外status属性，响应不变；显式允许列表确保这些值没有导出。纯社会输入干预保留真实几何输入不变，改变可见躯干倾角产生0.03155rad请求响应差异，改变躯干朝向产生约0.000873rad差异，几何响应完全相同。仍真实检查变化后的自身身体；没有把身体占地变化当作社会通道证据。另做多邻人左右对象的线索交换，检验响应依赖当前对象；排列、编号、同刻反向规划、低置信回退、短期状态清除、骨长、速率与预测/执行一致测试均有代码。

开发非对称局部相遇中，私有值+1人物在4.6秒到达、−1人物3.8秒先到，所有人均减速/避让；这是模型没有把私有值写成必然先通过规则的反例。路径长度刻意不同，**不能据此评价高地位是否仍被人感知**。对称相遇和镜像起点也保留，不把人工挑出的先后条件作泛化分数。

本轮没有心理学真值、独立受试者、自然性评分、可读性等效检验或新颖性证据。应先确认C1有可读status差异，再比较C2；两者都不可辨不能叫“保持”。正式非劣验证还需事先设下降界限与样本量依据。用户共设计反馈与独立观察者验证须分开。现阶段的地位映射可能主要反映源动作、姿态倾斜或短时注意，不能将内部e与私有值相关称为研究成功。

## 失败定位与成本解释

通道保留全部十人、原墙与26秒时限。失败日志显示反复无安全候选和长时间保持；互惠速度半平面本身不包含墙，墙只进入后续身体筛选，这仍可能限制脱困。候选日志保存了安全数量与执行拒绝，但未保存每一候选的完整分项淘汰门槛，所以不能唯一归因于墙、相对源姿态锥或互惠建议。`failure-diagnosis.json`逐人给出剩余路程、最长保持、无安全候选次数与互惠约束不可行次数。

30人压力场景保持原半径3.8、26秒，没有扩空间或缩角色。但初始18/19号已有0.065084身高代理重叠，属于初始化/密度容量失败。完整压力轨迹仍保留；此配置不能证明从安全初态发生了碰撞，也不能证明有效30人控制。需要另设事前验证的无重叠初态才能研究30人安全性，不能把本失败删除或当十人结果的外推。

复杂度约为 `N[M³ + K T (J+M) + C F J]`：每人M个近邻的二维互惠投影显式枚举边界交点并检验约束；K≤64、T=20个预测样本、J个骨节点；C×F为所有源周期样本的当前控制变换。密集场景的Python枚举、频繁约束重建，以及未到达者持续重规划都会增加成本。空闲终点帧使全段planning p50显得很小，不是实时性能证据。最终另测真实活动十人快照，见`isolated-benchmark.json`；浏览器播放流畅完全不能代替0.2秒规划预算验收。
